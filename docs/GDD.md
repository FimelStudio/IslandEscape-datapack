## v0.1 收束范围（当前多人测试口径）

v0.1 的正式测试目标是 **4–12 人隐藏身份感染撤离 PvP**：幸存者围绕信号塔推进撤离，1 名隐藏母体通过污染、转化和任务点压制阻止撤离。本文仍保留完整长期设计，但所有实现、平衡和测试优先以本节为准；若后续章节出现更大范围内容，默认视为 v0.2 / 实验模式 / 彩蛋储备。

| 分类 | v0.1 口径 |
|---|---|
| 核心体验 | 撤离 PvP + 隐藏身份 + 感染对抗 |
| 推荐人数 | 4–12 人；最佳首轮测试 6–10 人 |
| 主线机制 | 1 名母体、普通感染者、感染期、信号塔、直升机撤离、超时病毒结局、母体死亡清剿 |
| v0.1 可选 | 轮船路线、完整 10 职业池、隔离扫描、资源包模型与音效 |

| 实验模式 | 17–20 人双母体、Last Stand 枪战小游戏、特殊感染体扩展 |
| 暂缓 / 不进 v0.1 | 生涯系统、长期账户成长、复杂大厅匹配、X-7 母体伪装结局 |

## 一、设计目标

| 目标 | 设计取舍 |
|---|---|
| **信任崩塌** | 母体身份隐藏；普通感染者知道母体身份并围绕母体复活，形成感染阵营指挥链 |
| **节奏曲线** | 黄昏登岛 → 黑夜抢修 → 动态破晓 / 多线撤离，时长 15 分钟 |
| **不对称对抗** | 幸存者有 10 种差异化职业；母体 1 名 + 普通感染 |
| **多结局复玩** | 完整设计保留 6 种结局；v0.1 正式测试只把撤离胜 / 感染胜 / 清剿胜作为清晰结算 |
| **长期成长** | 生涯等级、专精、MVP 和徽章属于后续版本；v0.1 不提供长期账户成长或永久数值 |
| **原版可实现** | 仅依赖 1.21.x datapack，不依赖 mod / 资源包（资源包仅观感增强） |
| **弹性人数** | v0.1 正式支持 4–12 人；13–20 人和双母体只作实验模式，不作为首轮平衡基准 |

## 二、对局阶段时间线

对局前在海风号上进行，不计入 15 分钟。房主开始游戏后，按真实时间 15 分钟划分 5 个阶段。每个阶段切换由 tick 函数监听 `phase_timer` 积分板触发。

### Pre-game — 海风号大厅 / 餐厅准备（不计时）

- **进入地图**: 玩家出生在海风号大厅（`marker.lobby_ship`），这里是开始大厅，不存在感染、战斗或任务进度
- **准备区**: 玩家可传送到餐厅（`marker.dining_room`）就餐 / 看规则 / 等人，模拟事故前的普通乘客状态
- **开始方式**: 房主在大厅执行 `/function escape_island:game/start` 或点击开始交互
- **开局投放**: 开始后系统分配职业和道具，并把所有玩家随机分散传送到岛上不同 `marker.spawn_island` 点；避免所有人从同一海滩抱团出发
- **叙事效果**: 玩家像在事故后被冲散到岛上各处，开局天然产生信息差和路线选择，接近太空狼人杀 / 鹅鸭杀的分散行动感

```
0:00 ── 2:00 ─ 3:00 ───────────── 12:30 ───── 15:00
  P1      P2              P3           P3.5 / P4
 黄昏    觉醒       黑夜抢修       终局高压 / 动态撤离
                                                   超时 = P5 孢子升腾
```

### Phase 1 — 黄昏登岛（0:00 – 2:00）

- **玩家行为**: 从各自随机落点探索附近区域、确认职业道具、搜物资箱、读叙述书页
- **系统**: 全员状态 = 幸存者；锁定母体技能；屏蔽 PvP
- **重要**: 此阶段 **PvP 关闭**，避免开局乱杀。2:00 时再开启
- **事件**: 30 秒时全员收到"丛林深处咳嗽声"提示
- **生成**: 所有 `loot_basic` 容器刷新一次；每个玩家出生点 12 格内至少保证 1 个普通物资点或明显路径提示

### Phase 2 — 觉醒期（2:00 – 3:00）

- **2:00 触发**:
  - 系统从全体玩家中**隐秘随机选 1 人**为母体（叙事上等同"开局被柯尔文咬中的人"，详见 §三 母体选择）；17–20 人局同时隐秘预选第二人为**副母体**（详见 §十二）
  - 母体（及副母体）收到私聊 tellraw + 套装 + 母体专属道具；其人类背包被系统清空
  - 全员（含母体伪装）收到全图广播：`§7柯尔文不见了——他去找救援了？还是……`
  - 开启 PvP
- **2:10 叙事氛围事件（全员）**:
  - 全员 actionbar：`§8[环境] 丛林深处传来低沉嘶鸣——与方才的咳嗽声截然不同`
  - 播放 `ambient.cave` 音效（全图，音量略大于 P1 咳嗽声）
  - **设计意图**：叙事上暗示某种威胁已经苏醒，但不泄露姓名与方位；让幸存者开始互相警觉，同时给母体一段开场叙事烘托感
- **玩家行为**: 母体正式觉醒，但默认仍是伪装状态；此阶段更鼓励观察职业、靠近修复点制造轻微异常、寻找落单目标，而不是立刻无脑开团。其他人继续探索；信号网络离线事件提示在 2:30 出现
- **事件**: 2:45 触发"多座信号塔离线"全图广播

### Phase 3 — 黑夜抢修（3:00 – 15:00，直到撤离路线触发）

- 主舞台。常规胜负主要在此阶段形成。所有任务可执行：
  - 修复 5 座信号塔组成的信号网络（东、东南、西南、西北、中心核心塔）
  - 启动备用发电机（可选支线：提升抢修信号效率 / 缩短直升机倒计时）
  - 探索实验室（需主任笔记，主要提供备用疫苗 / 防毒面具 / 剧情线索；潜艇为隐藏撤离线）
  - 收集船舶部件并抢修船坞（按人数缩放，触发轮船路线）
  - 收集普罗米修斯文件（×3，触发毁灭岛屿）
- **撤离规则**: 轮船、潜艇、自爆路线不需要等天亮；完成条件后立刻进入对应撤离倒计时
- **主线破晓**: 信号网络总进度达到 100 触发动态破晓。发电机不再是硬门槛，而是让直升机路线更快、更稳。天空在直升机倒计时内逐渐变亮，直升机抵达时正好日出
- **环境事件**: 每 2 分钟随机一次（断电、无线电杂讯、幻觉），见 §九
- **12:30 终局高压**: 若此时仍没有任何撤离路线进入倒计时，系统广播孢子浓度上升，环境事件权重偏向风暴 / 菌丝爆发，母体获得一次短冷却变异窗口，逼迫双方进入最终决策而不是拖时间

### Phase 4 — 动态撤离（由任务触发）

- 任意逃生路线达成条件即进入 P4：
  - 信号网络总进度达到 100 → 动态破晓随直升机倒计时推进，90 秒后直升机在日出中抵达
  - 轮船修复 → 离港 45 / 50 / 60 秒倒计时（按人数缩放）
  - 实验室身份卡合成 → 潜艇启动 45 秒倒计时（隐藏路线，不作为常规胜率基准）
  - 自爆装置激活 → 3 分钟全图倒计时
- 母体伪装试剂 X-7 属于后续彩蛋路线；v0.1 / v0.2 主闭环稳定前不作为常规实现目标
- 直升机路线会改变全图天色；其他路线维持当前夜色和环境压迫感

### Phase 5 — 孢子升腾（15:00 时间到）

- 仅在没有任何幸存者完成逃生且时间到时触发
- 全员 title「阳光照进菌林，孢子开始升腾……」
- 5 秒内所有未撤离的幸存者被强制进入感染期
- 20 秒后全部转化 → 母体阵营胜利

## 三、阵营详细规则

### 幸存者阵营

- 开局所有玩家都是幸存者
- 队伍内**无 PvP 伤害**（避免误伤）。感染期玩家仍属于幸存者阵营，不能伤害其他幸存者，也不能把感染传给其他幸存者
- 实际 Minecraft `team` 只负责原版友伤免疫：健康幸存者、感染期玩家和伪装母体都在 `survivors` 队伍；猎手母体和普通感染者在 `infected` 队伍；不可复活死亡和结局等待进入 `spectator` 队伍
- 感染期不是"反叛期"，而是"救援倒计时": 玩家可以逃跑、呼救、继续做任务，但移动和交互效率下降，且超时会转化
- **感染期玩家可以尝试登机/登船/登艇**：进入 `state.boarding` 等待起飞。若等待期间感染期倒计时归零（转化发生），立刻被驱离至感染者阵营，无法撤离；若飞离 / 离港 / 潜航在转化前发生，则视为成功撤离——这是一场和时间的赌注
- 死亡条件:
  - 幸存者无论被母体、感染者、环境、坠落、溺水或爆炸杀死，都会进入 **15 秒孢化倒计时**，随后转化为普通感染者
  - 孢化倒计时期间进入**倒地孢化**：玩家本体锁定在死亡位置，不进入 spectator，不可移动、不可交互、不可攻击；actionbar 显示剩余秒数，本人仍能从倒地位置看见场上、听到队友语音/聊天
  - 其他玩家能看到玩家本体原地僵直和少量绿色孢子粒子；船医/疫苗无法救回已经死亡的玩家
  - 神父祝福若尚未消耗，会阻断这次死亡并清除感染期；祝福用完后再死亡也会转化为感染者
- 物品继承: 死亡时掉落非职业道具，职业道具锁定不掉

### 感染者阵营

#### 母体（1 人）

**选择规则**:
- T+0:00 开局时，系统可先隐秘预选一名"柯尔文咬伤目标"；T+2:00 才揭示并正式转为母体。实现上也可在 T+2:00 现场抽签，玩家体感必须等同于"早已被咬，只是现在发作"
- 仅母体本人收到通知 + 道具 + 状态切换；其他人无任何提示（无 boss bar、无 tellraw、无 sound 暗示）
- 17–20 人局同时预选第二人为**副母体**，双方互知身份，规则见 §十二 副母体

**觉醒物品处理**：T+2:00 收到母体私聊通知的同时，系统清空其持有的**所有人类物品**（武器、弹药、线缆等任务物资），并发放母体专属套装与全部技能道具。伪装母体的逻辑身份是感染阵营（`infected.mother + team.infected` tag），但实际 `team` 留在 `survivors`，且不拥有 `team.human` tag；这让母体无法借误伤或被误伤提前暴露。

**不可被治愈、不可复活**: 母体被打到 0 HP 后进入**母巢崩坏**，同一玩家不再复活为母体，并直接进入自由 spectator 等待结算。4–16 人局：母体死亡后，普通感染者失去复活能力；之后死亡的普通感染者也直接进入 spectator；场上所有活跃普通感染者全灭，幸存者立刻获得清剿胜利。17–20 人局的清剿条件见 §十二 副母体。母体因此更强、更危险，但必须谨慎选择出手时机。

**两种状态**:

母体从 T+2:00 起始终以**伪装状态**登场，必须主动**变异**才能切换至猎手状态（战斗状态）：

| | 伪装状态（默认） | 猎手状态 |
|---|---|---|
| **实际 team** | `survivors`（不带 `team.human` tag） | `infected` |
| **外观** | 与幸存者完全一致，无感染标识 | 头部显示凋零骷髅头；8 格内可见暗红粒子，附近玩家听到低沉异声 |
| **近战感染 / 伤害** | ✕ 无法攻击幸存者，也不会被幸存者误伤 | ✓ 有效命中 +34 污染，可被幸存者武器伤害 |
| **吞噬** | ✕ | ✓ |
| **腐痕感知** | ✓（追踪用，不暴露身份） | ✓ |
| **集群嚎叫** | ✓（只揭示母体存在，不暴露姓名） | ✓ |
| **被动孢子脉冲** | 连续贴近同一幸存者 6 秒后启动；4 格内每 10 秒对最近幸存者 +10 污染（低反馈、非连续） | 不生效（猎手期靠近战感染） |
| **侵蚀光环** | 3 格内正在修复任务点的幸存者修复速率 -15%；伴随极轻心跳音 | 不再生效（直接攻击更高效） |

**切换规则**:
- **伪装 → 猎手**：主动使用"变异脉冲"技能道具（右键）；播放变异粒子 + 异声（8 格内可听），不公告姓名
- **猎手持续 60 秒后自动回到伪装**（成长不会延长猎手时间）；再次变异有 45 秒冷却（4–7 人局为 30 秒）
- `state.hunting` 表示当前猎手战斗状态；`state.mutated` 只表示曾经变异过 / 留下扫描痕迹，不代表当前可战斗
- **提前回伪装（后续彩蛋）**：伪装试剂 X-7 可立刻从猎手状态强制回到伪装（全局限 1 次），覆盖 60 秒计时；该路线暂缓，不计入主闭环平衡

**身份揭示提示**:
- 首次使用腐痕感知 → 全图模糊提示"有什么东西在追踪你们"（不暴露姓名）
- 主动变异时 8 格内玩家听到异声（不公告姓名）
- 病毒学家在近距离可见"金色粒子"（两种状态下均有效，但不直接广播姓名）
- 幸存者可在指定设备处发起**隔离扫描**，得到"正常 / 孢子异常 / 严重异常"等模糊结果；它提供团队决策证据，但不是 100% 验母体按钮
- **没有任何单人机制能 100% 识别母体身份**——靠线索叠加、隔离扫描、走位和玩家推理形成共识

**侵蚀光环（伪装状态）的设计意图**:
- 给伪装期的母体一个不暴露身份的主动选项：站在修复点附近"假装帮忙"，让该位置的修复速率隐性降低 15%
- 受影响幸存者会得到极弱反馈：低频心跳、修复点偶发"信号受污染"提示；它不构成铁证，但能让玩家事后回想并产生可讨论线索
- 同步累积被动孢子脉冲（连续贴近 6 秒后，每 10 秒 +10）——母体必须真正承担贴身风险，不能路过就免费堆感染
- 受影响幸存者听到的"心跳音"音量极小，可被误以为是环境氛围或自己心理作用；多次出现才应成为怀疑依据

#### 副母体（17–20 人局第二名母体）

17–20 人局在选出主母体的同时，系统再隐秘预选一人为**副母体**。副母体与主母体构成双隐藏核心，幸存者面对的不再是"找出一个人"，而是"找出两个人"的更高难度身份推理。

**觉醒时机**：T+2:00 与主母体同时觉醒，独立收到私聊通知；双方互知对方身份，但彼此的行为不强制协调。

**技能与成长**：副母体拥有与主母体完全相同的技能（变异脉冲、腐痕感知、集群嚎叫、吞噬）和成长曲线（成长 I / II / III 在相同全局时间触发）。

**复活锚点**：感染者死亡后可在任意一名存活母体附近复活，双锚点让感染者队伍更难被彻底封锁。

**清剿规则（17–20 人局）**：
- 第一名母体死亡 → 该玩家**降级为普通感染者**：失去所有母体技能，但保留当前 HP 和成长加成；复活锚点转移至存活的第二名母体
- 第二名母体死亡 → 所有感染者失去复活能力，幸存者需清理剩余感染者才能获得清剿胜利
- **清剿胜利** = 两名母体均已死亡 + 场上所有感染者全灭

**给幸存者的线索**：系统不直接告知副母体存在数量；幸存者只在首次触发任一母体的腐痕感知时收到统一的模糊提示"有什么东西在追踪你们"，与标准局一致，不暴露是否有两名母体。

> 设计意图：双母体结构让"宣布我们找到母体了"的时刻不再终结局势；幸存者需要同时斩断两条指挥链，社交推理和战斗决策的难度和戏剧张力均上一个台阶。

#### 普通感染者（被转化的幸存者）

- 不可治愈、不可逆转
- HP 与转化前一致
- 攻击不再直接附带感染期，而是施加**孢子污染值**；污染值叠满后才进入感染期（普通感染者效率低于母体）
- 保留前世职业的"转化保留"被动（详见 §四）
- **知道母体身份**：普通感染者转化后能看到所有存活母体的方向 / 名牌，或收到私聊提示。感染阵营允许形成明确指挥链，斩首母体也因此成为幸存者的核心战略目标
- 母体存活时没有"早死旁观者"渠道；死亡会把玩家推向感染者阵营，保证每个人继续参与对局
- 母体存活时，死亡 = 25–30 秒后在母体附近 8–16 格复活，复活时此处冒出绿色粒子 + 阴森音效。复活时空手 + 短暂无敌/虚弱；幸存者可借击杀感染者获得战术喘息窗口，也可通过观察复活压力判断母体大致活动区域
- 母体死亡后，普通感染者不再复活；之后死亡的普通感染者直接进入自由 spectator。幸存者需要清理最后的活跃感染者才能结束游戏
- 母体存活时，感染者复活冷却期间不进入 spectator，不允许自由飞行侦察；玩家被锁定在死亡位置附近，只能看到有限局部信息和自己的复活倒计时

#### 循声者（Clicker，特殊感染体）

循声者是母体吞噬幸存者后直接产生的特殊感染体。被吞噬的幸存者**不经历孢化倒计时**，而是立刻转化为循声者实体，从母体所在位置释放出来。

**行为特征**：
- 只追踪**正在移动的幸存者**；完全静止的幸存者不在循声者追踪范围内
- 靠近幸存者后施加**孢子污染**（不造成直接伤害），迫使幸存者移动和分散注意力
- 在地图上发出持续嘶鸣音效（范围 12 格），构成可听到的威胁提示

**击杀方式**：
- 手枪 1 发命中即消灭（属于轻型感染实体）
- 近战武器 3 次命中消灭
- 消灭时在原地释放小型孢子爆炸：2 格半径内幸存者 +10 孢子污染

**阵营归属**：属于感染者阵营，计入感染者总数，影响清剿胜利判定。母体死亡（4–16 人局）或两名母体均死亡（17–20 人局）后，循声者失去行动能力并原地消散。

**数值**：HP、攻击孢子值与母体当前成长阶段挂钩（详见 [BALANCE.md](BALANCE.md) §循声者数值）。场上无硬上限；母体每次吞噬只产生 1 个。

**设计意图**：循声者是母体吞噬技能的延伸收益——不只是单次击杀，而是在消灭对方后留下一个持续骚扰单元。它迫使幸存者分出注意力和弹药，同时对静止防守的小队形成心理压迫（不敢停下来，否则循声者来了又得分心）。

### 视觉状态汇总

所有玩家在任意时刻都处于以下状态之一，各状态的视觉标识如下：

| 状态 | 对本人 | 其他玩家可见 |
|---|---|---|
| 幸存者（健康） | 正常 | 正常外观 |
| 孢子污染中（1–99） | ≥50 时 actionbar 个人警告 + 轻微心跳音 | **不可见** |
| 感染期（100，转化倒计时中） | 红色 vignette + 心跳音 + 脚下粒子 + 缓慢 I | 附近玩家可见弱红 / 金色粒子，方便救援 |
| 倒地孢化（死亡后 15s） | 视角锁在倒地位置 + actionbar 倒计时 + 低频心跳/孢化音 | 玩家本体原地僵直 + 绿色孢子粒子 |
| **普通感染者（完全转化）** | 正常视角 | **头部显示僵尸头** + 绿色孢子粒子（2 格半径） |
| 母体（伪装状态） | 正常 | **外观与幸存者完全一致，无任何感染标识** |
| 母体（猎手状态） | 正常 | **头部显示凋零骷髅头**；8 格内可见暗红粒子，附近玩家可听低沉异声 |
| 母体（X-7 强制伪装期间） | 正常 | 猎手粒子/音效关闭，对外完全显示为幸存者 |
| 母巢崩坏（母体死亡，4–16 人局） | 母体玩家进入自由 spectator | 感染者失去复活能力，幸存者清场即可胜利 |
| 副母体降级（17–20 人局首名母体死亡） | 降级玩家视角恢复为普通感染者 | **僵尸头 + 绿色孢子粒子**；母体标识消失；另一名母体仍隐藏 |
| 循声者（Clicker） | — | **名牌深绿（§2）+ 持续嘶鸣音效**；缩小的暗绿色轮廓；不可骑乘，只追移动目标 |

> 设计意图：普通感染者是**已知的、可见的威胁**；母体是**未知的、隐藏的威胁**；循声者是**已知的、快速移动的骚扰威胁**。两者的张力分工不同——幸存者面对感染者时是空间对抗，面对母体时是信息博弈。

### 隔离扫描（社交推理补强）

当玩家已经产生怀疑时，需要有一个正式但不绝对的行动选项，避免推理只变成口头争吵。

- **可用地点**: 中心核心塔、实验室终端、船坞医疗箱（正式地图可用 `marker.scan_station` 或复用上述 marker）
- **启动条件**: 2 名幸存者在目标玩家 3 格内同时读条 6 秒；目标离开范围、受到玩家攻击或读条者离开会中断
- **结果分级**:
  - `正常`: 未发现明显孢子异常
  - `孢子异常`: 目标可能处于污染积累、感染期、刚结束猎手状态，或附近存在伪装母体干扰
  - `严重异常`: 目标已感染期 / 已转化 / 猎手状态母体，或刚发生强烈变异痕迹
- **母体伪装交互**: 伪装母体不应被稳定一键验出；长期贴近修复点、刚结束猎手状态、或附近有病毒学家时，更容易显示异常
- **病毒学家加成**: 病毒学家参与读条时，读条时间 6 秒 → 4 秒，且结果更偏向正确分级
- **限制**: 每个扫描站 90 秒冷却；结果只给参与扫描者和目标附近玩家，不全图广播
- **设计目的**: 提供可执行的怀疑流程，但仍保留误判、拖延和社交博弈空间

## 四、10 职业完整描述

每职业开局获得 **1 主动技能道具 + 1 被动效果**。被动通过 tick 函数检测玩家 `tag` 持续应用。
转化后保留**1 项**"被动残影"作为反派烟幕，让幸存者难以光看战斗风格判断敌我。

具体数值见 [BALANCE.md](BALANCE.md)，下表给设计意图。

### 1. 船医 (Doctor)

- **核心**: 唯一可主动治愈感染期的职业
- **主动**: 解毒针 — 右键感染期队友，撤销其感染状态。冷却 90 秒。开局给 1 针，每 90 秒补给 1 针（最多持有 3 针）；**自救**：右键自身（处于感染期时）消耗 **1 针**，清除本次感染期，每个感染期限触发 1 次
- **被动**: 队友 5 格内回血速度 +50%；**自身孢子污染阈值 +30**（需积累至 130 才进入感染期，比普通幸存者多一次母体命中的缓冲）
- **武器**: 铁斧（标准）+ M-7 手枪（8 发）
- **转化保留**: 攻击附带 5 秒中毒——"医生还记得怎么注射，只是手里换了别的针剂"
- **设计意图**: 救援核心，需要在母体威胁下接近受害者，操作压力大；但她转化后仍能给同队感染者持续伤害支援，转化价值高

### 2. 船长 (Captain)

- **核心**: 团队增益，buff 半径内队友强
- **主动**: 哨子 — 丢出 → 半径 8 格队友速度 II + 力量 I 持续 15 秒。冷却 120 秒
- **被动**: 自身额外 4 点护甲（皮革甲套装）
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: "仇恨光环" — 半径 6 格内的友方感染者攻击 +20%
- **设计意图**: 高战力 + 团队 buff，但身份易暴露（人群中体型最壮、装备最齐），开局就是母体优先目标

### 3. 工程师 (Engineer)

- **核心**: 任务加速专家
- **主动**: 微型电池 — 放在修复点附近，使该点修复效率显著提升，持续 60 秒。冷却 60 秒；**右键已放置的电池可回收**（效果中止，冷却继续计时），允许跨点重新部署；所有加速仍受任务团队上限约束
- **被动**: 任何修复点（信号塔/发电机/船坞）站位修复时速度 +25%
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: 可对修复点造成回滚（同感染者破坏，但效率比普通感染者高）
- **设计意图**: 鼓励留守任务点，但因此成为母体明确目标；转化后是反向破坏王

### 4. 海军陆战队员 (Marine)

- **核心**: 战斗与控制
- **主动**: 压制射击 — 锥形音爆，3 格内目标减速 III 6 秒。冷却 45 秒
- **被动**: 自带皮革甲套装、抗击退、减少 1 点摔伤
- **武器**: 铁剑 + M-7 半自动手枪（开局 1 把 + **24 发**，是其他职业初始弹药的 3 倍；可在物资箱补充弹药）
- **转化保留**: 攻击附带 1 秒失明
- **设计意图**: 唯一开局有强控制的职业，是母体最忌惮的对手；转化后短暂失明也很烦人

### 5. 厨师 (Chef)

- **核心**: 食物 / 团队恢复，强响应性辅助
- **主动**: 热汤 — 右键即时治愈 4 心。**优先级**：5 格内若有感染期或低 HP（≤8）队友，自动对最近的此类队友释放（替代自愈）。若目标处于感染期，热汤只**暂停转化倒计时 8 秒并回血**，不清除感染期，避免抢走船医的唯一治愈定位。冷却 **120 秒**
- **被动**: "热餐光环" — 自身获得夜视；**8 格内**队友每 5 秒刷新短暂伤害吸收 I（离开范围后很快消失）。后期地图加入烹饪台据点后，可扩展为烹饪台附近侦察/补给互动
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留（v0.1 临时实现）**: "腐败热汤" — 感染者厨师的热汤技能改为对 5 格内最近的幸存者施加 +8 孢子污染 + 4 秒饥饿（伪装成误操作或环境伤害，不立即暴露身份）。汤锅放置版本（"变质热汤"概念）推迟到 Batch 10+ 实现
- **设计意图**: 厨师从纯自愈职业升级为响应式辅助；她能给救援争取时间，但不能替代船医。转化后制造区域孢子压力，是社交推理的种子

### 6. 通讯员 (Radio Operator)

- **核心**: 信息侦察
- **主动**: 信号扫描 — 立即生成一份私有异常信号报告，只把已转化感染者、感染期玩家、已暴露母体的距离区间发送给通讯员本人。冷却 120 秒
- **被动**: 信号识别 — 近距离准心对准其他玩家时，可查看其公开职业；隐藏/伪装母体显示为幸存者，暴露后的母体/感染者显示为信号异常。修复信号塔时个人速度 +25%
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留——信号欺骗者（Signal Forger）**：感染者通讯员掌握着信号网络的完整知识，转化后利用这份知识制造进度判断混乱，而不是提供真实情报。
  - **被动——进度雾化**（自动，45 秒触发间隔）：每 45 秒自动对所有幸存者的全局信号进度 bossbar 注入一次虚高显示（显示值 = 实际进度 + 15–25 随机），持续 8 秒后恢复真实值。幸存者若在此窗口查看进度，会误判为比实际更接近完成，可能降低修塔紧迫感。反制：反复查看 bossbar 并发现数字出现跳变，可推断场上存在感染者通讯员
  - **主动——塔位误报**（冷却 90 秒，单局最多 2 次；2 次耗尽后进入 3 分钟锁定）：激活后从当前进度未满 100 的信号塔中随机选一座，向全体幸存者广播假完成消息（`§a[信号网络] XX信号塔——修复完成`，格式与真实完成消息一致）。实际进度不变；被骗的幸存者可能放弃该塔转去他处，或误判总进度。反制：走到对应信号塔处发现进度未完成；或观察全局 bossbar 未真正上升
- **设计意图**：感染者通讯员的威胁是**信息层面**的，与幸存者通讯员给队友精准情报形成直接反向对应。两个能力均不直接伤人，但在协调困难的多人局中会造成显著的时间浪费和路线误判。

### 7. 病毒学家 (Virologist)

- **核心**: 反间谍
- **主动**: 检测剂 — 6 格内有母体、感染者或感染期玩家时屏幕泛红 + 音效。冷却 45 秒
- **被动**: 母体在距离 **8 格内**会留下金色粒子（只有病毒学家能看见）；5–8 格为偶发微粒、无音效，1–4 格为持续粒子 + 低频嗡鸣，提供方向感知；可手工合成"备用疫苗"（实验室 + 化学台原料，每局 1 支）
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: 攻击附带 3 秒反胃
- **设计意图**: 唯一能被动识别母体的职业，但范围极近且非确定性；非常稀有的证据来源

### 8. 机修工 (Mechanic)

- **核心**: 任务支援 + 区域拒止
- **主动**: 机关陷阱 — 放置一次性陷阱，触发后减速 II 4 秒并标记目标 30 秒。冷却 90 秒（最多场上 3 个）
- **被动**: 直升机 / 轮船 / 自爆装置修复 +30%；可拆卸自己或队友放置的陷阱
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: 可放置感染者陷阱（绊倒幸存者）；**每次在孢子点复活时自动获得 1 个感染者陷阱道具**（与母体装备重发机制一致），场上上限 1 个；感染者陷阱散发微弱绿色粒子（可被发现但需靠近），幸存者无法拆除
- **设计意图**: 通用工程师，覆盖工程师没碰的任务，副线路线（轮船 / 实验室）的关键

### 9. 运动员 (Athlete)

- **核心**: 高机动逃生与穿越地形
- **主动**: 肾上腺素 — 右键职业道具后持续 10 秒，冷却 120 秒，获得速度 I；持续期间滑铲速度提升 1.2 倍，滑铲体力消耗降低为 50%。物品栏显示冷却剩余秒数，职业道具防丢弃
- **技能**: 滑铲 — 跑动中前进 + 潜行触发，消耗体力向前贴地滑行；可通过 1.5 格高的空隙，可用空格提前结束，达到最大距离后自动停止。体力条仅在未满或体力不足时显示
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: 保留滑铲肌肉记忆，但肾上腺素职业道具不再补给
- **设计意图**: 运动员不是正面战斗职业，而是负责侦察、拉扯、救援路线试探和危险区域快速脱身；强处在位移选择，弱处在体力耗尽后没有额外保命手段

### 10. 神父 (Priest)

- **核心**: 一次性救命稻草
- **主动**: 十字架 — 90 秒内首次致死伤害免疫并清除感染期，单局只可用 1 次
- **被动**: 漆黑中视野略好（夜视 I 弱版）；阅读研究站书页时显示加密附注（神父持有时书页会多出 2–3 行原本被涂黑的内容，例如 Voss 主任笔记里隐藏的密码碎片）
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: "余烬" — 作为感染者死亡后的复活冷却 +10 秒，但复活时获得 10 秒**抗性 II + 速度 I**（能扛住大多数单次击退，构成接近不可打断的冲入窗口）
- **设计意图**: 神父不再制造早期旁观者，而是提供一次真正的"拒绝死亡"；若最终仍被转化，他会变成节奏较慢但复活后有危险冲入窗口的感染者——磨死他不划算，等他出现才是真正的威胁。神父的书页附注被动是自爆路线的隐藏触发器：**T+3:00 仅神父收到私聊引导**，鼓励主动寻找书页；找到 Voss 笔记后能看到涂黑的自爆密码碎片，是"毁灭岛屿"路线的关键信息源

## 五、感染与治愈状态机

```
                ┌────────────┐
                │ 幸存者状态 │ ←──┐
                └─────┬──────┘    │ 污染值自然衰减
```

### 孢子污染值

感染不再由单次攻击直接触发。母体和感染者的攻击会先叠加个人 `spore_load`，只有污染值达到 100 才进入感染期:

| 来源 | 污染值 | 设计意图 |
|---|---:|---|
| 母体有效近战命中（猎手状态）| +34 | 母体需要约 3 次干净命中才让目标进入感染期 |
| 母体被动孢子脉冲（伪装状态，4格内）| 连续贴近 6 秒后，每 10 秒 +10 | 约 10 个脉冲才单独触发感染期；有极弱心跳/污染提示，是隐蔽但可回忆的感染路线 |
| 普通感染者近战命中 | +27 | 普通感染者需要约 4 次命中（低于母体效率），压迫但不滚雪球 |
| 孢子云 / 菌丝爆发停留 5 秒 | +15 | 环境制造压力，不替感染者免费拿人头 |
| 实验室高浓度孢子 10 秒 | +10 | 推动实验室路线的紧张感 |

- 污染值在 15 秒未新增污染后开始衰减，每 5 秒 -15，最低为 0
- 进入感染期时污染值清零；被治愈后获得 20 秒 `state.infection_resist`，期间污染值获取减半
- 感染期玩家仍属于幸存者阵营，不能攻击其他幸存者，攻击其他幸存者也不会传播污染
- 感染期玩家可继续修理 / 携带物资 / 上交通工具，但修复和终端交互速度 -50%

**视觉/听觉提示**:
- 污染值 ≥ 50 时，玩家本人收到轻微心跳音与 actionbar 警告，其他人不可见
- 感染期玩家屏幕红色 vignette（display entity 实现）
- 心跳音效（30 秒内心跳渐密）
- 缓慢 I + 脚下落 portal 粒子
- 附近玩家可见弱红 / 金色粒子，便于判断救援窗口但不依赖名牌颜色

**治愈来源**:
| 来源 | 持有者 | 数量限制 | 备注 |
|---|---|---|---|
| 解毒针 | 船医 | 开局 1 针，90 秒补 1 针，最多 3 针 | 主要来源 |
| 备用疫苗 | 病毒学家手工合成 | 单局最多 1 支 | 需实验室原料 |
| 急救冷藏箱 | 实验室 `loot_rare` 容器 | 全局共 ~3 支 | 高风险高收益 |
| 神父祝福 | 神父 | 单局 1 次 | 同时也防 HP=0 转化 |

**感染期时长**: 进入感染期后默认 45 秒，随人数缩放；感染期由污染值触发，不再由单次攻击直接触发。

## 六、战斗系统（核心）

### 战斗哲学

> **抑制 > 击杀。**

- 母体设计为**极难击杀**，幸存者通过**减速、致盲、控制、逃跑**抑制母体节奏
- 母体是感染阵营核心，强于普通感染者，但不复活
- 幸存者可以做任务撤离，也可以集火斩首母体后清理剩余感染者
- 母体需要用追踪、吞噬和集群嚎叫指挥感染者创造机会，不能无脑换血
- 因此"杀母体" vs "做任务"是真实的策略选择：前者风险高、收益大；后者更稳，但会给母体成长时间

### 母体生命体系

| 项 | 数值 |
|---|---|
| HP | 初始 60（4–7人局 70），随成长最高约 70 |
| 自然护甲 | 4 点 |
| 脱战回血 | 5 秒未受伤后，1 HP/s |
| 击退抗性 | 80% |
| 攻击节奏（猎手状态）| 有效攻击冷却 2.5 秒；冷却中命中只播放擦刀反馈，不叠污染 |
| 近战感染（猎手状态）| 每次有效命中 +34 污染，约 3 次命中进入感染期 |
| 被动孢子脉冲（伪装状态）| 连续贴近同一幸存者 6 秒后，4 格内每 10 秒对最近幸存者 +10 污染；提供极弱反馈，作为怀疑线索 |
| 侵蚀光环（伪装状态）| 3 格内正在修复任务点的幸存者修复速率 -15%；不直接暴露身份 |
| 死亡规则 | 母体不复活；母体死亡后感染者失去复活能力 |
| 清剿胜利 | 母体死亡且场上普通感染者全灭时，幸存者立刻胜利 |

### 母体成长

母体随时间成长，强化追踪、团队和续航，少量强化正面战斗。成长从 T+2:00 觉醒开始计时。

| 阶段 | 时间 | 效果 |
|---|---:|---|
| 成长 0 | 觉醒时 | HP 60（4–7人局 70），攻击冷却 2.7 秒，腐痕感知范围 20 格 |
| 成长 I | 觉醒后 4 分钟（T+6:00） | 最大 HP +5（→ 65），腐痕感知范围 +4 格，吞噬恢复略提高；不瞬间回血；私聊成长通知 |
| 成长 II | 觉醒后 7 分钟（T+9:00） | 集群嚎叫持续 +3 秒；猎手持续和冷却不再随成长强化；私聊成长通知 |
| 成长 III | 觉醒后 10 分钟（T+12:00） | 最大 HP 再 +5（→ 70），母体附近感染者获得短暂速度/抗性脉冲；不瞬间回血；私聊成长通知 |

### 母体里程碑反馈

母体触发特定事件时，通过私聊 actionbar/title 收到反馈，**不广播给幸存者**，保持紧张感的同时让母体玩家感受到成长节奏：

| 事件 | 反馈（仅母体可见） |
|---|---|
| 成长 I 触发（T+6:00） | actionbar：`§4▲ 力量在增长 §8(+5 最大HP / 不再瞬间回血)` + sound `ambient.cave` |
| 成长 II 触发（T+9:00） | actionbar：`§4▲ 爪牙集结 §8(嚎叫增强 / 猎手不缩冷却)` + sound `ambient.cave` |
| 成长 III 触发（T+12:00） | actionbar：`§4▲ 完全进化 §8(+5 最大HP / 感染者脉冲)` + sound `entity.wither.ambient` |
| 首次成功感染（转化第 1 人） | title：`§4你的族群扩张了` + sound `entity.warden.roar`（仅母体） |
| 转化第 3 人 | actionbar：`§4同类已遍布岛上` |

> 设计意图：母体全程视野受限、信息最少，里程碑反馈让母体感知自身成长节点；v0.1 不让成长显著提高猎手覆盖率，避免先感染 1–2 人后迅速滚雪球。

### 普通感染者生命体系

| 护甲 | 0（除非生前是船长/海军陆战队员则保留装备） |
| 攻击附带污染值 | +27（4 次命中触发感染期，低于母体效率） |
| 脱战回血 | 1 HP/3s |
| 复活 | 母体存活时，死亡 → 25–30 秒后在母体附近 8–16 格复活，空手 + 短暂无敌/虚弱 |
| 母体死亡后 | 不再复活；死亡感染者留在死亡锁定状态 |
| 阵营败北 | 母体死亡且所有感染者全灭 |

#### 手枪设计要点

- M-7 是独立手枪系统：玩家体感为**右键射击**，空匣或潜行右键进入装填；不使用原版弩伤害、原版弩装填或一发一装填规则结算
- 当前 demo 命令使用 `minecraft:sugar` + `item_model="ie:glock_gun"` + `consumable.consume_seconds=0` 验证右键即时开火和 `ie:gunshot` 枪声；这只是框架样例，不限制最终载体必须是 sugar
- 最终实现应抽成"手枪适配层"：任意稳定右键载体都可以，只要能承载枪模型/枪声、识别 `custom_data.weapon = "pistol"`、记录弹匣并把输入交给手枪玩法层；不得使用原版弩伤害和一发一装填规则
- **弹匣 8 发**：连续射击共 8 发后必须装填
- **装填 2 秒**：装填期间无法射击但可移动，体感接近真枪而不是传统拉弓/蓄力远程
- **有效射击间隔 0.4 秒**：框架输入冷却是 0.2 秒，但实际扣弹/伤害结算由玩法层限制为 0.4 秒，避免全员手枪变成高射速对枪
- **子弹（Item: `iron_nugget` 自定义命名"9mm 弹药"）**：开局弹药用于自保；物资箱提供额外补给，约 4–7 人局 +15 发 / 8–12 人局 +25 发 / 13–20 人局 +40 发
- **全员开局自带 1 把手枪 + 8 发**，保证每名幸存者都有最低限度反抗能力；海军陆战队员开局 24 发
- **对母体伤害**: 手枪框架直接按目标类型结算，普通目标 6 damage，母体 4 damage（再受母体护甲/抗性影响）
- **击杀母体需要**: 约 24–35 发实际命中 + 控制配合；母体死亡不复活，但幸存者还需要清理剩余感染者 → 单人无法靠开局弹药稳定清剿

### 关键平衡保护

- 全员开局手枪提供安全感，但开局弹药只有 1 个弹匣；开枪是"争取距离/救人/打断追击"，不是主胜利路径
- 母体**自带护甲、抗性和手枪目标系数**：手枪对母体是削弱后的专门伤害，不套用原版远程武器伤害
- 母体随时间成长，越拖越擅长追踪、召集感染者和维持压迫
- 子弹/烟雾/闪光是**稀缺消耗品**: 物资箱配置为"一局总量约够全队 2 次正面遭遇"
- **感染需要叠压**: 单次命中只增加污染值，母体必须创造连续追击或把目标逼进孢子区，才能真正触发感染期
- **队友间无 PvP**: 幸存者互不伤害；感染期玩家仍是幸存者，不会因为误击制造硬证据
- **母体不能无脑换血**: 母体死亡后不复活，并会切断感染者复活能力

### 战斗节奏样本

> "三人正在抢修中心核心塔，母体扑出。Marine 反手压制射击减速母体，工程师丢电池继续修，运动员滑铲远遁后绕回侧翼丢烟雾弹掩护撤离。母体咬中厨师一次，厨师的 actionbar 显示孢子污染升高，但尚未进入感染期。母体试图二次贴身，船医和 Marine 合力掩护厨师撤出污染区，污染值开始衰减。母体怒离，核心塔进度重新开始推进。"

这是设计目标的"教科书回合"——所有人都在用工具和位置，没有人在"对枪"。

### 倒地状态（濒死救援）

> **暂不实现。设计已完成，待技术方案验证后实施。**

#### 设计目标

当幸存者被母体/感染者打至极低血量时，不立即死亡或转化，而是进入**倒地状态**——身体趴在地上，靠队友救援。这给团队制造"分兵救人 vs 继续任务"的决策张力，同时让单局失去队友的节奏更有层次感（不是一刀毙命，而是争分夺秒的窗口）。

#### 触发条件

- 幸存者受到战斗伤害（母体近战、感染者近战、循声者爆炸孢子）**HP 归零**时，拦截正常死亡事件，转入倒地状态（保留 1 HP）
- **不触发**：环境伤害、摔落伤害、感染期转化不进入倒地状态

#### 倒地期间规则

| 项 | 规则 |
|---|---|
| 动画 | 爬行姿势（趴地）：在玩家头顶 Y+1 处维持一个透明天花板实体，强制游戏进入爬行/游泳动作 |
| 移速 | 极慢（约 0.015，几乎无法移动） |
| 武器 | 无法使用任何武器/道具 |
| 孢子累积 | 暂停（防止倒地时被感染者再叠污染导致感染期叠加） |
| 倒计时 | 30 秒，归零后进入正常死亡 → 孢子化流程 |
| 呼救 | 倒地时广播一条提示给全体幸存者（不暴露位置，只提示有人倒地） |

#### 救援规则

- **任何幸存者**靠近倒地玩家 2 格内，持续站立 3 秒触发救援
- 船医（Doctor）救援时间减半（1.5 秒）
- 救援成功：恢复 8 HP，解除倒地状态，继续正常行动
- **二次倒地**：同一局内第二次倒地，直接跳过救援窗口，进入感染期（孢子污染跳满）

#### 设计意图

倒地状态制造"最后一刻救援"戏剧性，但不给幸存者无限容错——第二次倒地就是实质性的惩罚。母体和感染者会优先围住倒地玩家阻止救援，这是正确的战术行为。船医的价值因此进一步凸显。

#### 技术方案（暂不实现，待验证）

在 Minecraft 1.21.x 纯数据包下，爬行动画的触发需要玩家处于 ≤ 1 格净空间内。目前已知方案：

1. **透明天花板实体方案（首选）**：在玩家 Y+1 位置生成一个 `NoGravity:1b,Invisible:1b` 的高固体积实体（候选：潜影贝），每刻跟随玩家坐标。潜影贝收缩状态高度约 1 格，恰好触发玩家爬行。代价：潜影贝是 AI 实体，需完全关闭其 AI 并测试碰撞箱可靠性。
2. **视觉近似方案（回退）**：强制玩家潜行 + 极速减速，不产生正式爬行动画，但视觉上接近低伏姿态。无需额外实体，稳定性高，但动画不够准确。
3. **悬浮砖方案**：在玩家 Y+1 处生成 `NoGravity:1b` 的 `falling_block`（透明材质如 `minecraft:barrier`），障碍方块不渲染但有实体碰撞，理论上可触发爬行。需测试 falling_block 对玩家碰撞的可靠性。

> 建议：先用方案 2 验证玩法手感，若效果良好再升级为方案 1 或 3。

### 绝境援助协议（后期幸存者平衡）

> **暂不实现。设计已完成，平衡测试后决定具体参数。**

#### 背景与问题

随着感染者人数增加（常见后期：3 幸存者 vs 8+ 感染者），幸存者面临弹药耗尽、无法修任务、持续被围的困境，游戏进入"等死"阶段，体验急剧下降。

本机制不做"复仇女神"式的单人暴力强化（那会破坏恐怖/协作氛围），而是通过**系统层面降低撤离门槛** + **增加高风险援助资源** 来缓解压迫感，让绝境幸存者仍有合理的获胜路径。

#### A 方案：动态撤离加速（推荐主方案）

**触发条件**：场上存活幸存者数 ≤ `floor(初始幸存者数 / 3)`，且至少满足以下一条：
- 当前 Phase ≥ 3
- 感染者数量 ≥ 幸存者数量 × 2

**效果**：所有信号塔进入**紧急广播模式**，即使无玩家在场也以缓慢速率自动累积修复进度：
- 每座未完成边塔：每 5 秒 +1 进度（正常单人站塔约每 2 秒 +1）
- 中心核心塔：每 10 秒 +1 进度
- 有玩家站塔时不叠加（玩家效率优先）

**叙事包装**：触发时对幸存者广播 `[紧急协议] 孤岛自动广播系统启动——信号正在自动爬频，但速度极慢。`，营造"系统最后努力"的氛围。感染者不收到此广播。

**设计意图**：即便幸存者无法全程守塔，也能借助自动爬频积累进度。这不是"上帝模式"——感染者仍可通过靠近信号塔压制进度，最终仍是人数博弈，但绝境幸存者有了时间换取空间的可能性。

#### B 方案：应急补给坠落（辅助方案）

**触发条件**：存活幸存者 ≤ 3，且距上次补给坠落 ≥ 120 秒（防刷）。

**效果**：在地图预设的 3 个落点之一（随机）生成一个**红色应急补给箱**，包含：
- 手枪弹药 ×24
- 烟雾弹 ×2
- 闪光弹 ×1
- 急救包 ×1（可配合船医使用）

**风险设计**：补给箱落地时发出明显声音 + 30 格内的感染者在 actionbar 看到方向提示（`[孢子感知] 检测到异常补给信号，方位：XX`）。这给感染者"围点打援"机会，幸存者必须判断是否值得冒险取包。

**最多触发次数**：全局最多 2 次，防止补给泛滥破坏稀缺感。

#### C 方案：最后生还者光环（最后 1 人触发，备选）

> 仅在最后 1 名幸存者存活时触发（其余均已转化）。

**效果**（持续至对局结束或该玩家转化）：
- 移速 +15%
- 接受污染值降低 30%（更难被感染）
- 不受循声者听觉追踪（爬行噪声豁免）

**叙事包装**：私聊 title `你是最后的幸存者` + 全体广播 `[系统] 最后的希望——只剩一人。`（感染方和幸存方均可见，制造戏剧张力）。

**设计意图**：给"最后幸存者"一个勉强逃生的机会窗口，而不是必死的绝境。纯强化单人韧性（不是攻击力），符合"藏躲 + 完成任务"的游戏风格，不走 CF 复仇女神的暴力路线。

#### 优先级建议

| 方案 | 推荐 | 理由 |
|---|---|---|
| A 动态撤离加速 | ✅ 主要实现 | 无侵入性，融入任务系统，感染者仍有对策 |
| B 应急补给 | ✅ 辅助实现 | 高风险高回报，补充武器稀缺感 |
| C 最后生还者 | 可选 | 戏剧效果强，但可能让感染方觉得最后围杀偏难 |

> 复仇女神（单人爆发暴力强化）的风格与本作的恐惧/协作定位不符，不采用。

## 七、任务系统

### 主任务：呼叫直升机

#### 修复信号塔

- 主线改为 5 座信号塔组成的信号网络：东塔、东南塔、西南塔、西北塔、中心核心塔
- 四座边塔使用 `marker.signal_tower`；中心核心塔同时拥有 `marker.signal_tower` + `marker.signal_core`
- 每座塔有本地修复进度 0–100；完成后写入一次全局信号进度，不重复给分
- **边塔**：每 2 秒 +1 本地进度（单人 200 秒），完成后全局信号进度 **+25**
- **核心塔**：每 1.5 秒 +1 本地进度（单人 150 秒），完成后全局信号进度 **+25**
- 多人一起修会变快，但采用更收敛的软上限：1 人 100%，2 人 125%，3 人 140%，4 人及以上 150%
- 全局信号进度达到 100 = 信号网络接通 + 全图广播 + 触发直升机呼叫
- 操作: 持有线缆 + 站在修复点 + 长按右键；线缆作为维修工具，不建议每 1 点进度都消耗，避免主线变成纯开箱 RNG
- 修复中受到伤害、离开范围或松手会打断当前读条；已获得的本地进度不回退
- 感染者靠近信号塔优先制造占点压力：默认暂停修复；后续可加入短读条破坏，使本地进度小幅下降 10–15，而不是一脚清零

##### 双路径设计与"被蹲死一塔"应对

进度贡献构成（4 边 × 25 + 1 核 × 25 = 125，目标 100）刻意保留冗余，使任何单座塔都不是绝对必经：

| 路径 | 完成的塔 | 贡献 | 是否可行 |
|---|---|---|---|
| **路径 A**（推荐） | 3 边塔 + 核心塔 | 75 + 25 = 100 | ✓ 最快 |
| **路径 B**（应急） | 全部 4 边塔，绕开核心 | 100 | ✓ 核心塔被封时使用 |
| 旧捷径 | 2 边塔 + 核心塔 | 50 + 25 = 75 | ✗ **已封死** |
| 部分 | 3 边塔（无核心） | 75 | ✗ 不够 |

应对蹲守：
- 母体单人蹲死 1 座边塔 → 幸存者改修剩余 3 边 + 核心（路径 A 仍成立）
- 母体单人蹲死核心塔 → 幸存者改修全部 4 边塔（路径 B 成立）
- 母体 + 1 感染者同时分别蹲两座关键塔（如 1 边 + 核心）才会卡死路径——这种情况意味着感染方已经在场上人数与位置上占绝对优势，属于正常的后期压迫，不是设计死局

##### 4 人局节奏验算

3 名幸存者最优分工（路径 A，无干扰）：
- 阶段 1：3 人各修 1 座边塔，并行 200 秒 → 进度 75
- 阶段 2：3 人合修核心塔，150 ÷ 1.4 ≈ 107 秒 → 进度 100
- **合计：约 5.1 分钟**；母体干扰 +25–40% → **6.5–9 分钟完成**

设计目标：4 人局无人干扰时直升机主线约 5–6 分钟；有母体施压时约 7–10 分钟

#### 启动备用发电机

- 地图 2–3 个发电机（`generator` marker），主线支援目标，不是直升机硬门槛
- 收集**燃料电池**并右键发电机投入；小人数局 2 块，标准局 3 块
- 燃料投入不可被感染者偷走；发电机过载熄火只中断运行，不移除已投入燃料
- 投满燃料后进入 10 秒预热；预热完成后进入稳定运行倒计时
- 稳定运行时长按人数缩放（4–7 人 45 秒；8–12 人 60 秒；13+ 人 75 秒）；倒计时完成 → 视为发电完成
- 感染者 / 母体靠近发电机不会一脚归零，而是暂停稳定倒计时并积累「过载」
- 幸存者靠近并互动可降低过载；过载满时发电机熄火并进入故障状态，幸存者维修清空过载后重新预热，不需要重新投入燃料电池

##### 发电完成后的双重奖励

1. **全图修复速率 +20%**：所有信号塔（边/核）+ 轮船修复同时受益。在新版信号网络下，这能把 4 人局总修塔时间从约 5.1 分钟缩短到约 4.1 分钟
2. **直升机倒计时 90 秒 → 75 秒**：分兵收益再追加 15 秒
3. 综合：合理分兵做发电机大约可节省全局 70–80 秒；这才是值得冒险的真实奖励

发电机因此是有价值但非必做的战略投入：幸存者可分兵提速，母体可守发电机拖慢主线，形成真实的资源调度博弈。

#### 完成 → 直升机

- 信号网络全局进度达到 100 → 触发 **Dawn Sequence**，世界时间随直升机倒计时逐渐推进到日出
- Dawn Sequence 开始时启动 90 秒直升机倒计时；直升机不是等固定时间天亮，而是被玩家修好的信号"叫醒"
- 若发电机支线已完成，直升机倒计时可缩短为 75 秒，作为分兵冒险的奖励
- 直升机抵达时天色正好破晓，旋翼声和日出共同构成主线撤离的高潮
- 倒计时开始时广播随机降落点（4 个 `heli_pad` 中随机 1 个）
- 直升机使用 Animated Java 模型 `animated_java:helicopter/summon`，模型 root 标记为 `entity.helicopter`
- 倒计时最后 5 秒直升机从远处高空飞入；落地后开启 60 秒登机窗口
- 登机采用覆盖直升机整体的 `interaction` 判定，玩家右键机身范围 = 上机；模型本体只负责视觉，不承载骑乘
- 幸存者右键直升机后获得 `state.boarding` 并进入旁观等待起飞；感染者无法登机
- 感染期玩家可登机，但若在 60 秒等待窗口内转化，立刻被驱离（成为感染者，无法撤离）；飞离时仍是幸存者则成功撤离
- 母体伪装上机进入 8 秒扫描，扫描未被识破则触发伪装结局（后续彩蛋路线，主闭环稳定前暂缓）
- 直升机起飞动画先垂直升空，再向机头方向飞离；飞离结束后清理模型并进入撤离结算

### 副任务

#### 轮船维修（`ship_dock`）

- 轮船线定位为中速替代路线：比直升机少一个全图广播高潮，但需要搬运实体部件，并在狭窄船坞打一场最终争夺
- 收集船舶部件：螺旋桨、燃油泵、舵机连杆、启动电瓶、锚机绞盘
- 部件数量按人数缩放：4 人局 3 件（螺旋桨、燃油泵、舵机连杆）；5–7 人局 4 件（加启动电瓶）；8 人以上 5 件（再加锚机绞盘）
- 部件位置必须分散承担不同风险：沉船残骸提供视觉锚点，岩礁开阔易暴露，丛林深处易伏击，海风号附近距离近但适合母体埋伏，营地可顺手补给但绕路
- 4 人局至少 1 个部件应在远离船坞的高风险区，避免“开局贴海边捡三件直接修完”
- 携带至船坞，手持船舶部件长按右键约 1 秒投入；本局所需部件全部投入后才进入船体修复阶段
- 船体修复总进度 100；普通幸存者站船坞 +1/s
- 多人修复采用与信号塔相同的软上限：1 人 100%，2 人约 160%，3 人约 210%，4 人及以上约 250%；不再允许 4 倍速堆满
- 工程师、机修工、微型电池可以提升修复效率，但所有加成叠加后仍受 250% 团队上限约束；微型电池更适合作为“抢最后 20 点”的战术窗口
- 普通感染者站船坞 = 暂停幸存者修复并缓慢回退；母体站船坞 = 更强回退。推荐初值：普通感染者 -0.5/s，母体 -1/s，避免单人瞬间抹掉成果
- 设计目标：4 人局无人干扰时轮船线约 5–7 分钟；被母体盯防时约 8–10 分钟；它应比完美分工直升机略快，但比抱团直修直升机更容易被船坞卡点
- 进度满 = 船只启动登船窗口，并生成船舱 `interaction`；幸存者右键登船，感染者不能登船
- **登船窗口按人数缩放**：4–7 人 45 秒；8–12 人 50 秒；13+ 人 60 秒（避免大人数局集合不完）
- 轮船不需要等天亮；它的沉浸点是摸黑抢修、听着引擎咳嗽声离岸
- 注意: 船**不会等迟到**，窗口结束未上 = 留岛

#### 实验室（`lab_entrance`）

- 实验室在 v0.1 / v0.2 中优先定位为**高风险支援路线**，提供备用疫苗、防毒面具、隔离扫描终端、普罗米修斯文件等关键资源；潜艇撤离保留为高难隐藏路线，不作为常规胜率平衡基准
- 入口需「主任笔记」（`loot_keynote` 5 个候选位置随机 1 处刷出）
- 进入后地下迷宫，沿途生成「感染研究员」（高血量僵尸）；**研究员数量 = 当局所需身份卡碎片数**（按人数缩放，详见 §十二）
- 击杀每名研究员 → 必定掉落「员工身份卡碎片」(1 张/只)
- 集齐当局所需碎片到 `lab_terminal` → 长按右键 10 秒合成 → 解锁潜艇舱门；也可在此处进行隔离扫描
- 潜艇位于 `lab_sub`，玩家上座 → 45 秒倒计时撤离
- 感染者**不能进潜艇**（同直升机判定）
- 风险: 实验室内孢子浓度高，每 10 秒扣 0.5 心（除非有"防毒面具" — 实验室稀有掉落）

### 隐藏任务

#### 毁灭岛屿（彩蛋路线）

**触发条件**（必须全部满足才能在自爆装置交互）:
1. 持有 3 份「普罗米修斯文件」（从 5 个 `loot_keynote` 隐蔽候选点中固定刷出 3 份；位置难找，但单局不应随机无解）
2. 信号网络已接通（全局信号进度达到 100，保证有外界知情）
3. 实验室深处自爆终端（`island_bomb` marker）已激活

**激活流程**:
- 一名持有 3 份文件的幸存者走到自爆终端
- 长按右键：持有防毒面具时 **15 秒**，否则 **30 秒**；孢子浓度伤害不中断进度，**只有受到玩家攻击才归零**
- 激活后全图广播：「**W-7 自销毁系统启动，3:00 倒计时**」
- 自爆路线不需要等天亮；倒计时结束时直接结算毁灭岛屿
- 3 分钟内任意撤离方式逃出岛屿的人 → 该方判胜利

**胜利计算**:
- 至少 1 名幸存者在自爆倒计时结束前撤离 = 幸存者+岛屿毁灭，**Real Ending**
- 自爆完成时岛上还有人（含母体）= 全员死亡并转化失败，但幸存者方仍然胜（病毒被毁）
- 母体如果使用伪装试剂上了直升机 → 仍触发母体彩蛋（不会被自爆覆盖）

#### 母体伪装（母体彩蛋路线，暂缓）

> 该路线概念保留，但不进入 v0.1 / v0.2 主闭环平衡。待直升机、轮船、感染转化、隔离扫描和分层结局稳定后再实现，避免过早引入"突然被偷胜"的挫败感。

**触发条件**:
- 母体单独到实验室冷库（`lab_disguise` marker，藏在感染研究员区深处）
- 持有「员工身份卡碎片」x 2（仅母体可拾取，与幸存者所需的 4 张不冲突——是不同物品）
- 在冷库右键终端 → 获得「伪装试剂 X-7」

**使用**:
- 服用后 90 秒内母体对所有玩家显示为「幸存者」状态（标签变更，glowing 关闭，骨架显示恢复）
- 90 秒内成功上直升机 / 船 / 潜艇并通过 8 秒登载扫描 → **母体彩蛋胜利**
- 登载扫描期间全员收到一次模糊提示「生物识别出现异常」，不显示玩家名
- 通用反制：扫描 8 秒内任意幸存者攻击或重新右键直升机复核可打断母体登载，但不会直接暴露姓名
- 职业反制：若 8 格内病毒学家使用检测剂，伪装立即破裂，母体被击退并暴露 15 秒；否则扫描通过
- 90 秒过期未上交通工具 → 暴露 + 失败
- 注意: 这是母体**专属胜利路线**，与"感染所有人"并列。它允许戏剧性偷渡，但给幸存者留下一个短暂、需要职业配合的反制窗口

## 八、六个结局

### 分层胜负结算

撤离不再只有"至少 1 人上船就全队大胜"。普通撤离路线采用团队胜负 + 个人生还的双层结算：

| 玩家数 | 完整幸存者胜利需要撤离人数 | 低于阈值但有人撤离 |
|---|---:|---|
| 4–7 | 1 | 不适用，1 人撤离即完整胜利 |
| 8–12 | 2 | 惨胜 / 部分撤离 |
| 13–16 | 3 | 惨胜 / 部分撤离 |
| 17–20 | 4 | 惨胜 / 部分撤离 |

- **完整幸存者胜利**: 达到撤离阈值，幸存者阵营明确胜利
- **惨胜 / 部分撤离**: 有人活着离岛，但团队没有达到完整胜利阈值；结算文案强调代价惨重，不计作母体大胜
- **个人生还**: 已撤离玩家在结算面板标为"生还"，未撤离但阵营胜利的玩家标为"牺牲 / 留岛"
- **母体胜利**: 无幸存者撤离、全员转化，或 15:00 触发孢子升腾
- **清剿胜利（4–16 人局）**: 母体死亡且所有感染者（普通感染者 + 循声者）全灭，幸存者无需撤离即可获胜
- **清剿胜利（17–20 人局）**: 两名母体均已死亡（先死一名降级为普通感染者）且所有感染者全灭，幸存者立刻获胜

### 1. 直升机 — 幸存者标准胜

- **触发**: 信号网络总进度达到 100 → 动态破晓随 90 秒倒计时推进 → 直升机在日出时到达；若发电机支线完成，可缩短至 75 秒
- **判胜条件**: 起飞时幸存者登机人数达到分层胜利阈值；低于阈值则为惨胜 / 部分撤离
- **特别**: 上机时如有母体伪装在内 → 触发结局 5（伪装结局，后续彩蛋）

### 2. 轮船 — 幸存者次胜

- **触发**: 收集并投入本局所需船舶部件 + 修复进度 100%
- **判胜条件**: 登船窗口内幸存者登船人数达到分层胜利阈值；低于阈值则为惨胜 / 部分撤离
- **窗口**: 4–7 人 45 秒；8–12 人 50 秒；13+ 人 60 秒

### 3. 实验室潜艇 — 幸存者隐藏路线

- **触发**: 当局所需身份卡合成 + 潜艇启动
- **判胜条件**: 45 秒倒计时内登艇幸存者达到分层胜利阈值；低于阈值则为惨胜 / 部分撤离
- **特别**: 实验室优先是高风险支援路线；潜艇是隐藏撤离，不作为常规胜率基准

### 4. 毁灭岛屿 — 中立胜利（真结局）

- **触发**: 3 文件 + 信号网络已接通 + 自爆装置激活 + 自爆倒计时结束
- **判胜条件**: 自爆完成时病毒被毁。若倒计时结束前至少 1 名幸存者成功撤离，则显示 Real Ending；若无人撤离但自爆成功，显示"牺牲真结局"，幸存者阵营仍视为摧毁病毒

### 5. 母体伪装 — 母体彩蛋胜（暂缓）

- **触发**: 母体服用伪装试剂 X-7 后 90 秒内上交通工具并通过扫描
- **判胜条件**: 扫描通过即母体彩蛋胜。该路线暂缓实现，不参与主闭环平衡

### 6. 病毒变异 — 母体默认胜（Bad End）

- **触发**: 15:00 时间到 + 没有任何幸存者成功撤离，或所有幸存者在 15:00 前全部完成转化
- **判胜条件**: 时间到时无幸存者已撤离 / 场上无幸存者存活 → 母体胜
- **特别**: 全员强制感染期 + 20 秒后转化结算
- **提前变异（子情景）**: 若所有幸存者在 15:00 到来前全部完成转化，立刻触发病毒变异结局，不等 15:00。结局画面文案一致：「阳光照进菌林，孢子开始升腾……」

### 结局优先级

如果同时满足多个结局，按优先级触发:

```
母体伪装已通过登载扫描 > 毁灭岛屿真结局 > 清剿胜利 > 直升机/轮船/潜艇完整胜利/惨胜 > 病毒变异
```

例如自爆已激活、直升机也到达：普通幸存者撤离按毁灭岛屿真结局结算；但母体若已在任意交通工具上通过 8 秒伪装扫描，则优先触发母体伪装结局。未通过扫描的伪装状态不会覆盖自爆结局。

### 多撤离路线并行处理

幸存者有可能同时完成多条撤离路线（如轮船修好倒计时中 + 信号网络也接通启动直升机）。处理规则：

- 多条撤离路线可同时进入倒计时，互不冲突，bossbar 同时展示
- 以**第一个完成飞离 / 离港 / 潜航结算的路线**判定本局普通撤离结局，并按该路线撤离人数套用完整胜利 / 惨胜阈值
- 已登上"先完成路线"的幸存者视为该路线的幸存者；其他路线的倒计时被强制结束、未登载玩家就地继续身份
- 若两条路线在同一 tick 内同时触发登载结算（极端边界），按叙事重要性排序：**直升机 > 轮船 > 潜艇**
- 自爆倒计时不受其他路线影响，3 分钟归零时无论其他路线状态都直接触发毁灭判定（仍受上方"结局优先级"约束）

## 十一、训练模式与结算观战

### 训练模式 (`function escape_island:training/start`)

- 单人加载，适用于摸熟职业 / 测试技能
- 自动给所有 10 套职业道具（可切换） + 母体技能（debug 标签）
- 任务点开放无限刷新
- 时间锁定不前进
- 无胜负、无结局

### 结算观战模式

- 进入条件:
  - 主动放弃（菜单中 "/function escape_island:player/give_up"）
  - 直升机 / 船 / 潜艇撤离成功 → 在结算屏蔽期间进入观战，不再参与场上交互
  - 整局结算完成后所有人进入观战 / 结算空间
- 权限: gamemode spectator，可自由飞行，看所有玩家
- 限制: 不能与场上玩家交互、聊天受限于"全员公屏"或"观众频道"（自定义命令实现）
- 原则: 对局中死亡不进入旁观者，也不能自由飞行；除主动放弃外，早死玩家会先倒地孢化，再转化为感染者继续参与

### 复盘 (`function escape_island:debug/show_state`)

任意阶段可由观众或房主查看:
- 当前阶段 / 时间余量
- 母体玩家名（仅对 OP 显示）
- 各任务进度
- 已感染玩家列表
- 已死亡玩家列表

## 十二、缩放规则（4–20 人弹性）

| 玩家数 | 母体配置 | 感染期时长 | 信号网络目标 | 部件数 | 身份卡碎片 / 研究员数 | 轮船登船窗口 |
|---|---|---|---|---|---|---|
| 4 | 1 | 55 秒 | 总进度 100（4边×25 + 核×25） | 3 | 3 / 3 | 45 秒 |
| 5–7 | 1 | 50 秒 | 同上 | 4 | 3 / 3 | 45 秒 |
| 8–12 | 1 | 45 秒 | 同上 | 5 | 4 / 4 | 50 秒 |
| 13–16 | 1 | 40 秒 | 同上 | 5 | 4 / 4 | 60 秒 |
| 17–20 | 1 主母体 + 1 副母体 | 40 秒 | 同上 | 5 | 5 / 5 | 60 秒 |

### 小人数局母体强化

4–7 人局母体初始 HP 提升至 **70**（标准局 60），以补偿幸存者数量少、协作能力弱对母体的不利影响。成长上限同样上移 +10（成长后最高约 80）。

### 小人数局职业池（4–7 人）

4–7 人局分配职业时，**船医**必须出现在非母体幸存者中。实现上：先确定母体，再检查剩余幸存者职业；若没有船医，则优先把最后一名非母体普通职业替换为船医。若原本抽到船医的人后来成为母体，也必须在剩余幸存者中补 1 名船医。

其余职业从 10 个职业中完全随机；8 人及以上局使用完整随机池，不保证特定职业出现。

### 副母体（17–20 人局）

17–20 人局在主母体的基础上增加一名**副母体**，构成双隐藏核心，显著提升幸存者的信息推理难度和感染阵营的战略灵活性。

**觉醒与通知**：
- T+2:00 与主母体同时觉醒；副母体收到独立私聊通知和完整母体套装
- 双方各自收到对方的玩家名（互知身份），但不强制协调行动
- 全体幸存者不收到任何关于副母体存在的提示（无人数、无姓名）
- 副母体的觉醒物品清除规则与主母体相同：人类背包在 T+2:00 清空

**技能与成长**：
- 副母体拥有与主母体完全相同的技能：变异脉冲、腐痕感知、集群嚎叫、吞噬（含循声者产生）
- 成长阶段与主母体同步：同一全局时间触发 I / II / III 阶

**复活锚点**：
- 感染者死亡后可在任意一名存活母体附近 8–16 格复活；存活两名母体时，优先选择距死亡位置最近的母体

**死亡降级规则**：
- 第一名母体（主或副均可）被击杀 → 该玩家**立刻降级为普通感染者**：失去所有母体技能和复活锚点能力，但保留当前 HP 和成长阶段的属性加成（护甲、抗性等效果消除）；名牌从隐藏改为§c红色，外观与普通感染者一致
- 复活锚点自动转移至存活的第二名母体
- 第二名母体被击杀 → 所有感染者失去复活能力，进入清理阶段

**清剿胜利（17–20 人局）**：两名母体均死亡 + 场上所有感染者（含被降级的前母体、普通感染者、循声者）全灭 = 幸存者清剿胜利

**给幸存者的线索**：与标准局一致，全图只收到"有什么东西在追踪你们"的模糊提示，不透露母体数量；幸存者需要通过社交推理和观察复活规律（两处不同方向的复活压力）来推断存在两名母体

### 每局随机初始变量

熟悉地图后固定的布局会削减悬念感。以下变量在每次 `game/start` 时随机决定，让第 10 局也有"不一样"的开局判断：

| 变量 | 范围 | 实现 |
|---|---|---|
| **主任笔记位置** | 5 个候选点随机 1 处 | 已实现（`loot_keynote` 随机） |
| **隐患发电机** | 2 台发电机中随机 1 台开局 over_load = 8（需先处理才能稳定运行） | `apply_scaling.mcfunction` 末尾随机写入 overload |
| **物资热区** | 随机 1 个普通物资 marker 升级为稀有物资（视觉不变，开出更好物品） | `place_loot_chests` 随机将 1 个 `loot_basic` → `loot_rare` |

> 原则：随机变量只改变"探索路线"和"初始关注点"，不影响主任务完成时间或核心胜利条件。

> 数值具体调参见 [BALANCE.md](BALANCE.md) 的"缩放函数"章节。

## 十三、天赋系统

新版天赋系统废弃旧的"6 选 2 永久数值加成"方案，改为 **人格牌组**：

- 像《黎明杀机》一样，每名玩家赛前带入一组可形成打法的 perk
- 像《第五人格》一样，天赋被分成救援、修理、牵制、情报四条人格路线，并有强力核心人格
- 每局额外抽取 1 张不可预知的 **命运牌**，让同一套构筑也会出现不同局内节奏

旧方案的问题：

- 天赋太少，6 选 2 很快会被玩家解出固定答案
- 多数效果是永久数值，例如移速、夜视、伤害，强但不戏剧化
- 天赋没有冷却、代价和触发窗口，玩家缺少"我现在要不要交牌"的判断
- 母体替换只是把幸存者数值换成母体数值，缺少隐藏身份玩法里的反转感
- 随机性主要依赖职业随机，没有让同一职业在不同局里产生足够变化

### 设计意图

- **构筑感**：玩家赛前选择自己的打法倾向，例如救援位、修理位、牵制位、侦察位
- **局内戏剧性**：强天赋多为条件触发，带冷却、消耗或副作用，制造关键时刻
- **反身份博弈**：同一张人格牌有幸存者面和母体面；被选为母体后自动翻面，不暴露赛前选择
- **随机变化**：命运牌每局随机，不可指定；它不是核心强度来源，而是让计划出现偏差和惊喜
- **反最优解**：限制同类叠加和永久速度/伤害，避免所有人都选同一套

### 选择流程

```
Pre-game 大厅
  ↓
右键天赋 NPC
  ↓
从已解锁的人格牌中选择 1 个核心人格 + 2 个支线人格
  ↓
开局时系统随机补 1 张命运牌
  ↓
分配职业 / 觉醒母体
  ↓
幸存者保留正面效果；母体玩家的人格牌全部翻到母体面
```

### 构筑规则

每名玩家最终拥有 4 个天赋槽：

| 槽位 | 来源 | 作用 |
|---|---|---|
| 核心人格 | 玩家选择 1 个 | 类似第五人格终极人格，定义这局主要打法 |
| 支线人格 A | 玩家选择 1 个 | 提供中等强度的条件效果 |
| 支线人格 B | 玩家选择 1 个 | 与职业或路线形成组合 |
| 命运牌 | 开局随机 1 个 | 每局变化源，轻量但会改变选择 |

限制：

- 同一名玩家最多携带 1 个牵制位移类天赋
- 生涯系统只解锁更多可选人格牌和预设栏位，不增加天赋槽数量
- 全局修复速度加成受任务自身上限约束，不能靠多人堆天赋秒修
- 信息天赋只能给距离、方向、异常迹象，不能直接报出"谁是母体"
- 战斗天赋偏向拖延、撤退、打断，不提供稳定击杀母体的硬增伤
- 命运牌不允许成为构筑核心；它只能改变局部路线、资源或一次性机会

### 四条人格路线

| 路线 | 适合玩家 | 玩法关键词 |
|---|---|---|
| 救援 | 船医、神父、船长，以及愿意跟队的人 | 护送、救感染期队友、倒地前争取时间 |
| 修理 | 工程师、机修工、通讯员 | 抢任务窗口、降低打断损失、路线推进 |
| 牵制 | 运动员、海军陆战队员、船长 | 拉扯、断追、骗母体交变异 |
| 情报 | 通讯员、病毒学家、神父 | 判断路线、发现异常、制造团队共识 |

### 核心人格示例

核心人格强度高，但都有明显条件或冷却。它们应该制造"刚好活下来"、"刚好拖住"、"刚好抢完"这种局内记忆点。

| 核心人格 | 幸存者面 | 母体面 |
|---|---|---|
| **化险为夷** | 你治愈感染期队友、护送队友登上交通工具或在倒地孢化前靠近队友时，双方获得短暂速度/抗性，冷却长 | 首次让幸存者进入感染期后，短时间重置追踪节奏，鼓励母体继续压迫救援链 |
| **破窗余势** | 被母体或感染者命中后，若未处于疲劳，获得短暂加速，随后进入疲劳 | 命中刚脱离视线的目标后获得短暂追猎加速，帮助母体完成收割 |
| **临危专注** | 在修理点连续操作数秒未被打断后，短时间提高本人的交互效率；受伤立刻失效 | 母体破坏修理点时留下短暂腐蚀，幸存者需要重新争夺位置 |
| **旧讯号** | 完成一个任务阶段后，获得一次私有路线提示或异常方向提示 | 幸存者完成任务阶段时，母体获得模糊方位感和一次干扰通讯机会 |
| **孤注一掷** | 附近队友很少时，修理/投入/登船动作略快，但受到污染增加 | 单独行动的幸存者更容易被母体追踪，鼓励抓落单 |
| **回光返照** | 任意撤离路线开启时，清除自身迟缓/失明并获得短暂冲刺；单局一次 | 任意撤离路线开启时，母体变异冷却刷新，并获得一段终局追猎窗口 |

### 支线人格示例

支线人格比核心人格弱，更多是塑造习惯和微决策。

| 路线 | 支线人格 | 设计作用 |
|---|---|---|
| 救援 | **急救手法** | 治愈、解毒、自救后的抗污染窗口略长 |
| 救援 | **并肩而行** | 与感染期或倒地孢化队友靠近时，自己获得短暂抗性，但移动略慢 |
| 救援 | **最后留言** | 进入倒地孢化时给附近队友一个短暂异常方向提示 |
| 修理 | **稳手** | 任务读条被轻微位移打断时有一次缓冲 |
| 修理 | **备件意识** | 首次投入线缆、燃料或船舶部件后，私有提示下一个推荐路线点 |
| 修理 | **搜刮路线** | 首次打开物资点时更容易获得路线消耗品，而不是纯战斗物资 |
| 牵制 | **泥地步法** | 减速、陷阱、孢子云的持续时间略短 |
| 牵制 | **烟幕训练** | 自己受烟雾/闪光负面影响更短，投掷控场物更可靠 |
| 牵制 | **硬撑** | HP 低于阈值时首次受到非致命伤害，获得短暂抗性但进入长冷却 |
| 情报 | **疑心** | 有玩家长时间贴近你时获得心跳提示，不显示姓名和阵营 |
| 情报 | **地图记忆** | 访问过的关键点再次靠近时显示当前路线状态 |
| 情报 | **静默搜索** | 搜刮和阅读书页时声音/粒子更弱，适合偷偷走隐藏路线 |

### 命运牌

命运牌在开局投放后抽取。玩家不能指定，只能看到自己抽到了什么。

| 命运牌 | 效果方向 |
|---|---|
| **多余弹匣** | 开局额外获得少量 9mm 弹药 |
| **湿透地图** | 首次进入黑夜抢修期时获得一个最近任务点方向提示 |
| **旧钥匙** | 第一次长按任务交互的前 1 秒自动完成 |
| **船舱记忆** | 轮船路线相关交互略快，但实验室交互无加成 |
| **冷库印象** | 实验室高浓度孢子首次伤害被抵消 |
| **坏天气老手** | 第一次风暴/断电影响时间缩短 |
| **口袋绷带** | 第一次脱战后自动恢复少量生命 |
| **无线电回声** | 第一次环境事件触发时获得一个私有异常方向提示 |

命运牌的目标不是公平地增强每个人，而是让玩家每局临时调整计划：抽到船舱记忆的人更想推轮船，抽到冷库印象的人更愿意去实验室，抽到无线电回声的人会更适合抱团决策。

### 转化后的保留规则

- 普通感染者不再完整保留幸存者天赋，只保留"感染回声"
- 感染回声只保留原天赋约 30–50% 的强度，且偏向追击、干扰、复活节奏
- 这样可以保留"他生前是什么打法，转化后仍有影子"的趣味，但不会让强幸存者构筑在感染阵营变成双倍收益

示例：

| 幸存者构筑倾向 | 转化后的感染回声 |
|---|---|
| 救援 | 复活后短时间更耐打，但追击能力不强 |
| 修理 | 靠近任务点时破坏效率略高 |
| 牵制 | 复活后短时间速度略高，但持续短 |
| 情报 | 靠近幸存者时更容易收到模糊方向反馈 |

### 保存与重置

- 玩家选择存储为 `talent.core.*` 与 `talent.minor.*` tag
- 命运牌存储为 `talent.fate.*` tag，每局开始时随机写入
- 开局后 tag 伴随整个对局；转化时由 `talent/echo_on_infect` 生成感染回声 tag
- 母体觉醒时由 `talent/flip_mother` 把已选人格翻到母体面
- `game/start` 与 `game/settle` 清除所有 `talent.*` tag

> 数值细节见 [BALANCE.md](BALANCE.md) §十一；生涯解锁关系见 §十四。

## 十四、生涯与 MVP 系统

生涯系统的目标不是让老玩家永久更强，而是让每局结束后都有可展示、可回忆、可积累的长期目标。它提供称号、徽章、天赋选择范围和预设栏位，但不提供永久伤害、移速、生命、修理速度等直接数值优势。

### 设计原则

- **长期目标**: 玩家能看到自己在变成什么类型的玩家，例如救援位、修理位、牵制位、情报位或感染位
- **公平竞技**: 生涯等级不增加天赋槽，不给永久战斗属性；新玩家仍有完整基础构筑
- **高光记忆**: 每局自动选出 MVP 和多个高光奖项，让失败局也能留下"我这局做得很好"的反馈
- **反刷分**: 同一目标、同一任务点、同一事件的重复行为递减计分，防止互刷
- **天赋依赖**: 生涯系统解锁更多人格牌选择和天赋预设，不直接增强已选天赋效果

### 生涯数据

每名玩家长期保存以下数据：

| 数据 | 作用 |
|---|---|
| 生涯等级 | 代表总体游玩经验，解锁称号、徽章展示、天赋预设栏位 |
| 生涯 XP | 每局结算获得，用于提升生涯等级 |
| 救援专精 | 由治疗、护送、救感染期队友、靠近倒地队友等行为提升 |
| 修理专精 | 由修塔、修船、启动发电机、投入路线物品等行为提升 |
| 牵制专精 | 由被追击后存活、打断母体、控场救人等行为提升 |
| 情报专精 | 由信号扫描、隔离扫描、发现异常、共享路线判断等行为提升 |
| 感染专精 | 由感染、转化、压制任务点、协助母体围猎等行为提升 |
| MVP 次数 | 记录全局 MVP / 阵营 MVP / 高光奖项次数 |
| 荣誉徽章 | 记录稀有成就，用于大厅展示和结算面板 |

### 结算流程

```
游戏结束
  ↓
统计阵营结果与撤离层级
  ↓
统计每名玩家本局贡献分
  ↓
选出全局 MVP / 阵营 MVP / 高光奖项
  ↓
开放 15 秒玩家点赞
  ↓
发放生涯 XP、专精 XP、徽章和称号
  ↓
展示结算面板
```

### MVP 类型

| 类型 | 说明 |
|---|---|
| 全局 MVP | 本局综合贡献最高的玩家，胜负双方都可获得 |
| 幸存者 MVP | 幸存者阵营贡献最高，重视任务、救援、撤离和控场 |
| 感染 MVP | 感染阵营贡献最高，重视污染、转化、压制任务和守撤离点 |
| 高光奖项 | 可多人获得，例如最佳救援、最佳修理、最佳牵制、最佳情报、最佳猎手、绝境生还 |

4 人局可只展示全局 MVP + 高光奖项，避免结算面板太碎。

### MVP 计分方向

幸存者侧主要奖励：

- 推进信号塔、发电机、轮船、实验室和自爆路线
- 治愈感染期、暂停转化倒计时、护送感染期队友成功撤离
- 控制 / 击退猎手状态母体，帮助队友脱离追击
- 参与隔离扫描并得到有效异常结果
- 在终局完成登机、登船、登艇或真结局关键操作

感染侧主要奖励：

- 母体使幸存者进入感染期或完成转化
- 普通感染者参与污染、击倒、围堵和任务点压制
- 母体存活到终局或成功守住撤离点
- 触发病毒变异、造成惨胜而非完整幸存者胜利
- 复活后有效回场，而不是无意义送死

### 高光奖项示例

| 奖项 | 条件 |
|---|---|
| 最佳救援 | 救援贡献最高 |
| 最佳修理 | 任务推进贡献最高 |
| 最佳牵制 | 被母体 / 感染者追击后存活和拖延贡献最高 |
| 最佳情报 | 扫描、隔离扫描、异常提示贡献最高 |
| 最佳猎手 | 母体追猎、感染、转化贡献最高 |
| 最佳感染者 | 普通感染者污染、压制、守点贡献最高 |
| 绝境生还 | 感染期倒计时低于 5 秒仍成功撤离 |
| 岛屿之心 | 参与真结局关键步骤 |

### 生涯与天赋的关系

天赋系统默认开放一套基础池，保证新玩家也能正常构筑。生涯系统只影响"可选择的牌更多"和"换构筑更方便"：

| 生涯条件 | 解锁 |
|---|---|
| 默认 | 每条路线基础核心人格与基础支线人格 |
| 对应专精达到入门等级 | 解锁该路线更多支线人格 |
| 对应专精达到熟练等级 | 解锁该路线更多核心人格或命运牌变体 |
| 生涯等级提升 | 解锁称号、MVP 展示边框、天赋预设栏位 |
| MVP / 高光奖项累计 | 解锁展示徽章，不提供局内数值 |

限制：

- 每局仍然只能带 1 核心人格 + 2 支线人格 + 1 命运牌
- 解锁不会让同一张天赋数值变强
- 生涯等级不会提高血量、伤害、移速、修理速度或感染效率
- 未解锁的高级人格不能成为唯一答案；基础池必须覆盖救援、修理、牵制、情报四种打法

### 生涯展示

大厅中可通过生涯 NPC 打开个人档案：

- 生涯等级 / XP
- 五类专精等级
- 最近 5 局 MVP / 高光记录
- 常用职业和常用路线
- 已解锁称号、徽章、天赋预设

结算时展示本局获得：

- 生涯 XP
- 专精 XP
- MVP / 高光奖项
- 新解锁的天赋、称号或徽章

### 保存与重置

- 生涯数据跨局保存，不在 `game/start` 或 `game/settle` 中清空
- 本局贡献分使用 `match.*` scoreboard，每局开始清空
- 若需要测试或赛季重置，由 OP 执行专用 debug 函数清空生涯数据
