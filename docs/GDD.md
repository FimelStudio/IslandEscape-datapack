## 一、设计目标

| 目标 | 设计取舍 |
|---|---|
| **信任崩塌** | 母体身份隐藏；普通感染者保留生前职业被动技能 |
| **节奏曲线** | 黄昏登岛 → 黑夜抢修 → 动态破晓 / 多线撤离，时长 15 分钟 |
| **不对称对抗** | 幸存者有 10 种差异化职业；母体 1 名 + 普通感染 |
| **多结局复玩** | 6 种结局（含彩蛋），每结局触发条件不同 |
| **原版可实现** | 仅依赖 1.21.x datapack，不依赖 mod / 资源包（资源包仅观感增强） |
| **弹性人数** | 4–20 人，关键参数（任务量、感染期时长、母体血量）随玩家数自动缩放 |

## 二、对局阶段时间线

对局前在海风号上进行，不计入 15 分钟。房主开始游戏后，按真实时间 15 分钟划分 5 个阶段。每个阶段切换由 tick 函数监听 `phase_timer` 积分板触发。

### Pre-game — 海风号大厅 / 餐厅准备（不计时）

- **进入地图**: 玩家出生在海风号大厅（`marker.lobby_ship`），这里是开始大厅，不存在感染、战斗或任务进度
- **准备区**: 玩家可传送到餐厅（`marker.dining_room`）就餐 / 看规则 / 等人，模拟事故前的普通乘客状态
- **开始方式**: 房主在大厅执行 `/function escape_island:game/start` 或点击开始交互
- **开局投放**: 开始后系统分配职业和道具，并把所有玩家随机分散传送到岛上不同 `marker.spawn_island` 点；避免所有人从同一海滩抱团出发
- **叙事效果**: 玩家像在事故后被冲散到岛上各处，开局天然产生信息差和路线选择，接近太空狼人杀 / 鹅鸭杀的分散行动感

```
0:00 ── 2:00 ─ 3:00 ───────────────────── 15:00
  P1      P2              P3 / P4
 黄昏    觉醒       黑夜抢修 / 动态撤离
                                             超时 = P5 孢子升腾
```

### Phase 1 — 黄昏登岛（0:00 – 2:00）

- **玩家行为**: 从各自随机落点探索附近区域、确认职业道具、搜物资箱、读叙述书页
- **系统**: 全员状态 = 幸存者；锁定母体技能；屏蔽 PvP
- **重要**: 此阶段 **PvP 关闭**，避免开局乱杀。2:00 时再开启
- **事件**: 30 秒时全员收到"丛林深处咳嗽声"提示
- **生成**: 所有 `loot_basic` 容器刷新一次；每个玩家出生点 12 格内至少保证 1 个普通物资点或明显路径提示

### Phase 2 — 觉醒期（2:00 – 3:00）

- **2:00 触发**:
  - 系统从全体玩家中**隐秘随机选 1 人**为母体（叙事上等同"开局被柯尔文咬中的人"，详见 §三 母体选择）
  - 母体收到私聊 tellraw + 套装 + 母体专属道具
  - 全员（含母体伪装）收到"柯尔文消失了"提示
  - 开启 PvP
- **玩家行为**: 母体可开始下手；其他人继续探索；信号塔损坏事件提示在 2:30 出现
- **事件**: 2:45 触发"信号塔损坏"全图广播

### Phase 3 — 黑夜抢修（3:00 – 15:00，直到撤离路线触发）

- 主舞台。所有任务可执行：
  - 修信号塔（需线缆 ×5）
  - 启动备用发电机（需燃料电池 ×3 / 任一发电机即可）
  - 探索实验室（需主任笔记，触发 lab 路线）
  - 收集船舶部件（默认 ×5，按人数缩放，触发轮船路线）
  - 收集普罗米修斯文件（×3，触发毁灭岛屿）
- **撤离规则**: 轮船、潜艇、自爆路线不需要等天亮；完成条件后立刻进入对应撤离倒计时
- **主线破晓**: 只有信号塔 + 发电机完成会触发动态破晓。天空在直升机 90 秒倒计时内逐渐变亮，直升机抵达时正好日出
- **环境事件**: 每 2 分钟随机一次（断电、无线电杂讯、幻觉），见 §九

### Phase 4 — 动态撤离（由任务触发）

- 任意逃生路线达成条件即进入 P4：
  - 信号塔 + 发电机修好 → 动态破晓随直升机倒计时推进，90 秒后直升机在日出中抵达
  - 轮船修复 → 离港 30 秒倒计时
  - 实验室身份卡合成 → 潜艇启动 45 秒倒计时
  - 自爆装置激活 → 3 分钟全图倒计时
- 母体可在此阶段使用**伪装试剂 X-7**（如已找到）
- 直升机路线会改变全图天色；其他路线维持当前夜色和环境压迫感

### Phase 5 — 孢子升腾（15:00 时间到）

- 仅在没有任何幸存者完成逃生且时间到时触发
- 全员 title「阳光照进菌林，孢子开始升腾……」
- 5 秒内所有未撤离的幸存者被强制进入感染期
- 20 秒后全部转化 → 母体阵营胜利

## 三、阵营详细规则

### 幸存者阵营

- 开局所有玩家都是幸存者
- 队伍内**无 PvP 伤害**（避免误伤）。感染期玩家仍属于幸存者阵营，不能伤害其他幸存者，也不能把感染传给其他幸存者
- 感染期不是"反叛期"，而是"救援倒计时": 玩家可以逃跑、呼救、继续做任务，但移动和交互效率下降，且超时会转化
- 死亡条件:
  - 幸存者无论被母体、感染者、环境、坠落、溺水或爆炸杀死，都会进入 **15 秒孢化倒计时**，随后转化为普通感染者
  - 孢化倒计时期间进入**倒地孢化**：玩家本体锁定在死亡位置，不进入 spectator，不可移动、不可交互、不可攻击；actionbar 显示剩余秒数，本人仍能从倒地位置看见场上、听到队友语音/聊天
  - 其他玩家能看到玩家本体原地僵直和少量绿色孢子粒子；船医/疫苗无法救回已经死亡的玩家
  - 神父祝福若尚未消耗，会阻断这次死亡并清除感染期；祝福用完后再死亡也会转化为感染者
- 物品继承: 死亡时掉落非职业道具，职业道具锁定不掉

### 感染者阵营

#### 母体（1 人）

**选择规则**:
- T+0:00 开局时，系统可先隐秘预选一名"柯尔文咬伤目标"；T+2:00 才揭示并正式转为母体。实现上也可在 T+2:00 现场抽签，玩家体感必须等同于"早已被咬，只是现在发作"
- 仅母体本人收到通知 + 道具 + 状态切换
- 其他人无任何提示（无 boss bar、无 tellraw、无 sound 暗示）
- 17–20 人局额外预选 1 名"潜伏宿主"，见 §十二 缩放规则

**不可被治愈、不可复活**: 母体被打到 0 HP 后进入**母巢崩坏**，同一玩家不再复活为母体。母体死亡后，普通感染者失去复活能力；若场上所有普通感染者也全部死亡，幸存者立刻获得清剿胜利。母体因此更强、更危险，但必须谨慎选择出手时机。

**两种状态**:

母体从 T+2:00 起始终以**伪装状态**登场，必须主动**变异**才能切换至猎手状态（战斗状态）：

| | 伪装状态（默认） | 猎手状态 |
|---|---|---|
| **外观** | 与幸存者完全一致，无感染标识 | 8 格内可见暗红色粒子边框；附近玩家听到低沉异声 |
| **近战感染** | ✕ 无法通过攻击叠孢子 | ✓ 有效命中 +34 污染 |
| **吞噬** | ✕ | ✓ |
| **腐痕感知** | ✓（追踪用，不暴露身份） | ✓ |
| **集群嚎叫** | ✓（只揭示母体存在，不暴露姓名） | ✓ |
| **被动孢子散发** | 2 格内 +2/s（极慢，需长期贴近） | 同左（叠加近战效率） |

**切换规则**:
- **伪装 → 猎手**：主动使用"变异脉冲"技能道具（右键）；播放变异粒子 + 异声（8 格内可听），不公告姓名
- **猎手持续 60 秒后自动回到伪装**（静默回退，无额外提示）；再次变异有 45 秒冷却
- **提前回伪装**：使用伪装试剂 X-7 可立刻从猎手状态强制回到伪装（全局限 1 次），覆盖 60 秒计时

**身份揭示提示**:
- 首次使用腐痕感知 → 全图模糊提示"有什么东西在追踪你们"（不暴露姓名）
- 主动变异时 8 格内玩家听到异声（不公告姓名）
- 病毒学家在 4 格内可见"金色粒子"（两种状态下均有效）
- **没有任何机制能 100% 识别母体身份**——靠玩家推理

#### 普通感染者（被转化的幸存者）

- 不可治愈、不可逆转
- HP 与转化前一致
- 攻击不再直接附带感染期，而是施加**孢子污染值**；污染值叠满后才进入感染期（普通感染者效率低于母体）
- 保留前世职业的"转化保留"被动（详见 §四）
- **看不见母体身份**（防止开局猜中后做最后通牒）
- 没有"早死旁观者"渠道；死亡会把玩家推向感染者阵营，保证每个人继续参与对局
- 母体存活时，死亡 = 25–30 秒后在母体附近 8–16 格复活，复活时此处冒出绿色粒子 + 阴森音效。复活时空手 + 短暂无敌/虚弱；幸存者可借击杀感染者获得战术喘息窗口
- 母体死亡后，普通感染者不再复活。幸存者需要清理最后的感染者才能结束游戏
- 复活冷却期间不进入 spectator，不允许自由飞行侦察；玩家被锁定在死亡位置附近，只能看到有限局部信息和自己的复活倒计时

### 视觉状态汇总

所有玩家在任意时刻都处于以下状态之一，各状态的视觉标识如下：

| 状态 | 对本人 | 其他玩家可见 |
|---|---|---|
| 幸存者（健康） | 正常 | 正常外观 |
| 孢子污染中（1–99） | ≥50 时 actionbar 个人警告 + 轻微心跳音 | **不可见** |
| 感染期（100，转化倒计时中） | 红色 vignette + 心跳音 + 脚下粒子 + 缓慢 I | 名牌显示金色虹膜 emoji |
| 倒地孢化（死亡后 15s） | 视角锁在倒地位置 + actionbar 倒计时 + 低频心跳/孢化音 | 玩家本体原地僵直 + 绿色孢子粒子 |
| **普通感染者（完全转化）** | 正常视角 | **名牌变红（§c）+ 绿色孢子粒子（2 格半径）** |
| 母体（伪装状态） | 正常 | **外观与幸存者完全一致，无任何感染标识** |
| 母体（猎手状态） | 正常 | 8 格内可见暗红色粒子边框；附近玩家可听低沉异声 |
| 母体（X-7 强制伪装期间） | 正常 | 猎手粒子/音效关闭，对外完全显示为幸存者 |
| 母巢崩坏（母体死亡） | 母体玩家进入死亡锁定视角 | 感染者失去复活能力，幸存者清场即可胜利 |

> 设计意图：普通感染者是**已知的、可见的威胁**；母体是**未知的、隐藏的威胁**。两者的张力分工不同——幸存者面对感染者时是空间对抗，面对母体时是信息博弈。

## 四、10 职业完整描述

每职业开局获得 **1 主动技能道具 + 1 被动效果**。被动通过 tick 函数检测玩家 `tag` 持续应用。
转化后保留**1 项**"被动残影"作为反派烟幕，让幸存者难以光看战斗风格判断敌我。

具体数值见 [BALANCE.md](BALANCE.md)，下表给设计意图。

### 1. 船医 (Doctor)

- **核心**: 唯一可主动治愈感染期的职业
- **主动**: 解毒针 — 右键感染期队友，撤销其感染状态。冷却 90 秒。开局给 1 针，每 90 秒补给 1 针（最多持有 3 针）；**自救**：右键自身（处于感染期时）消耗 **1 针**，清除本次感染期，每个感染期限触发 1 次
- **被动**: 队友 5 格内回血速度 +50%；**自身孢子污染阈值 +30**（需积累至 130 才进入感染期，比普通幸存者多一次母体命中的缓冲）
- **武器**: 铁斧（标准）+ M-7 手枪（8 发）
- **转化保留**: 攻击附带 5 秒中毒——"医生还记得怎么注射，只是手里换了别的针剂"
- **设计意图**: 救援核心，需要在母体威胁下接近受害者，操作压力大；但她转化后仍能给同队感染者持续伤害支援，转化价值高

### 2. 船长 (Captain)

- **核心**: 团队增益，buff 半径内队友强
- **主动**: 哨子 — 丢出 → 半径 8 格队友速度 II + 力量 I 持续 15 秒。冷却 120 秒
- **被动**: 自身额外 4 点护甲（皮革甲套装）
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: "仇恨光环" — 半径 6 格内的友方感染者攻击 +20%
- **设计意图**: 高战力 + 团队 buff，但身份易暴露（人群中体型最壮、装备最齐），开局就是母体优先目标

### 3. 工程师 (Engineer)

- **核心**: 任务加速专家
- **主动**: 微型电池 — 放在修复点附近，使该点修复速度 +200% 持续 60 秒。冷却 60 秒；**右键已放置的电池可回收**（效果中止，冷却继续计时），允许跨点重新部署
- **被动**: 任何修复点（信号塔/发电机/船坞）站位修复时速度 +50%
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: 可对修复点造成回滚（同感染者破坏，但效率比普通感染者高）
- **设计意图**: 鼓励留守任务点，但因此成为母体明确目标；转化后是反向破坏王

### 4. 海军陆战队员 (Marine)

- **核心**: 战斗与控制
- **主动**: 压制射击 — 锥形音爆，3 格内目标减速 III 6 秒。冷却 45 秒
- **被动**: 自带皮革甲套装、抗击退、减少 1 点摔伤
- **武器**: 铁剑 + M-7 半自动手枪（开局 1 把 + **24 发**，是其他职业初始弹药的 3 倍；可在物资箱补充弹药）
- **转化保留**: 攻击附带 1 秒失明
- **设计意图**: 唯一开局有强控制的职业，是母体最忌惮的对手；转化后短暂失明也很烦人

### 5. 厨师 (Chef)

- **核心**: 食物 / 团队恢复
- **主动**: 热汤 — 放置共享回血锅，5 分钟内任何人靠近右键饮用回 4 心。冷却 180 秒
- **被动**: "热餐光环" — 自身获得夜视；5 格内队友获得短暂伤害吸收 I（离开范围后很快消失）。后期地图加入烹饪台据点后，可扩展为烹饪台附近侦察/补给互动
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: "变质热汤" — 他生前留下的热汤锅在他转化后会在 3 秒内逐渐变质：名称改为"变质热汤"，冒出微弱绿色粒子，并失去"可饮用"提示。误饮不会直接触发感染期，只会获得 8 秒饥饿 + 3 秒反胃，并增加少量孢子污染；幸存者可通过靠近观察或直接破坏汤锅来规避
- **设计意图**: 保留"热汤变成风险点"的反差，但给幸存者明确读条、视觉提示和处理方式；厨师转化后制造的是区域压力，不是无预警背刺

### 6. 通讯员 (Radio Operator)

- **核心**: 信息侦察
- **主动**: 信号扫描 — 立即生成一份私有异常信号报告，只把已转化感染者、感染期玩家、已暴露母体的距离区间发送给通讯员本人。冷却 120 秒
- **被动**: 信号识别 — 近距离准心对准其他玩家时，可查看其公开职业；隐藏/伪装母体显示为幸存者，暴露后的母体/感染者显示为信号异常。后续信号塔任务中可获得修复速度 +50%
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: "虚假扫描" — 转化保留方案待重做：不再使用全员可见轮廓，后续改为污染通讯员收到的异常信号报告
- **设计意图**: 关键时刻提供感染阵营压力点情报，但不会把隐藏/伪装母体直接扫出来；职业识别只读取公开身份，不承担验母体功能

### 7. 病毒学家 (Virologist)

- **核心**: 反间谍
- **主动**: 检测剂 — 6 格内有母体、感染者或感染期玩家时屏幕泛红 + 音效。冷却 45 秒
- **被动**: 母体在距离 **8 格内**会留下金色粒子（只有病毒学家能看见）；5–8 格为偶发微粒、无音效，1–4 格为持续粒子 + 低频嗡鸣，提供方向感知；可手工合成"备用疫苗"（实验室 + 化学台原料，每局 1 支）
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: 攻击附带 3 秒反胃
- **设计意图**: 唯一能被动识别母体的职业，但范围极近且非确定性；非常稀有的证据来源

### 8. 机修工 (Mechanic)

- **核心**: 任务支援 + 区域拒止
- **主动**: 机关陷阱 — 放置一次性陷阱，触发后减速 II 4 秒并标记目标 30 秒。冷却 90 秒（最多场上 3 个）
- **被动**: 直升机 / 轮船 / 自爆装置修复 +30%；可拆卸自己或队友放置的陷阱
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: 可放置感染者陷阱（绊倒幸存者）；**每次在孢子点复活时自动获得 1 个感染者陷阱道具**（与母体装备重发机制一致），场上上限 1 个；感染者陷阱散发微弱绿色粒子（可被发现但需靠近），幸存者无法拆除
- **设计意图**: 通用工程师，覆盖工程师没碰的任务，副线路线（轮船 / 实验室）的关键

### 9. 运动员 (Athlete)

- **核心**: 高机动逃生与穿越地形
- **主动**: 肾上腺素 — 右键职业道具后持续 10 秒，冷却 120 秒，获得速度 I；持续期间滑铲速度提升 1.2 倍，滑铲体力消耗降低为 50%。物品栏显示冷却剩余秒数，职业道具防丢弃
- **技能**: 滑铲 — 跑动中前进 + 潜行触发，消耗体力向前贴地滑行；可通过 1.5 格高的空隙，可用空格提前结束，达到最大距离后自动停止。体力条仅在未满或体力不足时显示
- **武器**: 铁剑 + M-7 手枪（8 发）
- **转化保留**: 保留滑铲肌肉记忆，但肾上腺素职业道具不再补给
- **设计意图**: 运动员不是正面战斗职业，而是负责侦察、拉扯、救援路线试探和危险区域快速脱身；强处在位移选择，弱处在体力耗尽后没有额外保命手段

### 10. 神父 (Priest)

- **核心**: 一次性救命稻草
- **主动**: 十字架 — 90 秒内首次致死伤害免疫并清除感染期，单局只可用 1 次
- **被动**: 漆黑中视野略好（夜视 I 弱版）；阅读研究站书页时显示加密附注（神父持有时书页会多出 2–3 行原本被涂黑的内容，例如 Voss 主任笔记里隐藏的密码碎片）
- **武器**: 铁斧 + M-7 手枪（8 发）
- **转化保留**: "余烬" — 作为感染者死亡后的复活冷却 +10 秒，但复活时获得 10 秒**抗性 II + 速度 I**（能扛住大多数单次击退，构成接近不可打断的冲入窗口）
- **设计意图**: 神父不再制造早期旁观者，而是提供一次真正的"拒绝死亡"；若最终仍被转化，他会变成节奏较慢但复活后有危险冲入窗口的感染者——磨死他不划算，等他出现才是真正的威胁。神父的书页附注被动是自爆路线的隐藏触发器：**T+3:00 仅神父收到私聊引导**，鼓励主动寻找书页；找到 Voss 笔记后能看到涂黑的自爆密码碎片，是"毁灭岛屿"路线的关键信息源

## 五、感染与治愈状态机

```
                ┌────────────┐
                │ 幸存者状态 │ ←──┐
                └─────┬──────┘    │ 污染值自然衰减
                      ▼            │
              被咬伤/孢子云污染     │
                      │            │
                      ▼            │
                ┌────────────┐    │
                │ 孢子污染值 │ ───┘
                │  0–100     │
                └─────┬──────┘
                      │ 污染值 ≥ 100
                      ▼
                ┌────────────┐    │
                │  感染期    │ ←──┐ 解毒针/疫苗/急救冷藏箱
                │ (45 秒)    │    │ （感染期内可用）
                └─────┬──────┘
                      │
        ┌─────────────┼─────────────┐
        │             │             │
        ▼             ▼             ▼
   神父祝福      HP=0/任意死亡    45s 超时
   (限 1)        (孢化15s)       (自然转化)
        │             │             │
        ▼             ▼             ▼
   清除感染     感染者状态     感染者状态
   恢复幸存                 (不可逆)
```

### 孢子污染值

感染不再由单次攻击直接触发。母体和感染者的攻击会先叠加个人 `spore_load`，只有污染值达到 100 才进入感染期:

| 来源 | 污染值 | 设计意图 |
|---|---:|---|
| 母体有效近战命中（猎手状态）| +34 | 母体需要约 3 次干净命中才让目标进入感染期 |
| 母体被动孢子（伪装状态，2格内）| +2/s | 极慢，约 50 秒贴近才触发；隐蔽感染路线 |
| 普通感染者近战命中 | +35 | 普通感染者需要约 3 次命中，压迫但不滚雪球 |
| 孢子云 / 菌丝爆发停留 5 秒 | +15 | 环境制造压力，不替感染者免费拿人头 |
| 实验室高浓度孢子 10 秒 | +10 | 推动实验室路线的紧张感 |

- 污染值在 15 秒未新增污染后开始衰减，每 5 秒 -15，最低为 0
- 进入感染期时污染值清零；被治愈后获得 20 秒 `state.infection_resist`，期间污染值获取减半
- 感染期玩家仍属于幸存者阵营，不能攻击其他幸存者，攻击其他幸存者也不会传播污染
- 感染期玩家可继续修理 / 携带物资 / 上交通工具，但修复和终端交互速度 -50%

**视觉/听觉提示**:
- 污染值 ≥ 50 时，玩家本人收到轻微心跳音与 actionbar 警告，其他人不可见
- 感染期玩家屏幕红色 vignette（display entity 实现）
- 心跳音效（30 秒内心跳渐密）
- 缓慢 I + 脚下落 portal 粒子
- 玩家显示牌挂"金色虹膜"emoji（其他玩家肉眼可见）

**治愈来源**:
| 来源 | 持有者 | 数量限制 | 备注 |
|---|---|---|---|
| 解毒针 | 船医 | 开局 1 针，90 秒补 1 针，最多 3 针 | 主要来源 |
| 备用疫苗 | 病毒学家手工合成 | 单局最多 1 支 | 需实验室原料 |
| 急救冷藏箱 | 实验室 `loot_rare` 容器 | 全局共 ~3 支 | 高风险高收益 |
| 神父祝福 | 神父 | 单局 1 次 | 同时也防 HP=0 转化 |

**感染期时长**: 进入感染期后默认 45 秒，随人数缩放；感染期由污染值触发，不再由单次攻击直接触发。

## 六、战斗系统（核心）

### 战斗哲学

> **抑制 > 击杀。**

- 母体设计为**极难击杀**，幸存者通过**减速、致盲、控制、逃跑**抑制母体节奏
- 母体是感染阵营核心，强于普通感染者，但不复活
- 幸存者可以做任务撤离，也可以集火斩首母体后清理剩余感染者
- 母体需要用追踪、吞噬和集群嚎叫指挥感染者创造机会，不能无脑换血
- 因此"杀母体" vs "做任务"是真实的策略选择：前者风险高、收益大；后者更稳，但会给母体成长时间

### 母体生命体系

| 项 | 数值 |
|---|---|
| HP | 初始 60（4–7人局 70），随成长最高约 75 |
| 自然护甲 | 4 点 |
| 脱战回血 | 5 秒未受伤后，1 HP/s |
| 击退抗性 | 80% |
| 攻击节奏（猎手状态）| 有效攻击冷却 2.5 秒；冷却中命中只播放擦刀反馈，不叠污染 |
| 近战感染（猎手状态）| 每次有效命中 +34 污染，约 3 次命中进入感染期 |
| 被动孢子（伪装状态）| 2 格内持续 +2 污染/s；约 50 秒连续贴近才能触发感染期 |
| 死亡规则 | 母体不复活；母体死亡后感染者失去复活能力 |
| 清剿胜利 | 母体死亡且场上普通感染者全灭时，幸存者立刻胜利 |

### 母体成长

母体随时间成长，强化追踪、团队和续航，少量强化正面战斗。成长从 T+2:00 觉醒开始计时。

| 阶段 | 时间 | 效果 |
|---|---:|---|
| 成长 0 | 觉醒时 | HP 60（4–7人局 70），攻击冷却 2.7 秒，腐痕感知范围 20 格 |
| 成长 I | 觉醒后 3 分钟 | 最大 HP +5（→ 65），腐痕感知范围 +4 格，吞噬恢复略提高；私聊成长通知 |
| 成长 II | 觉醒后 6 分钟 | 攻击冷却降至 2.5 秒，集群嚎叫持续 +3 秒，感染者复活时间 -5 秒；私聊成长通知 |
| 成长 III | 觉醒后 9 分钟 | 最大 HP +10（→ 75），母体附近感染者获得短暂速度/抗性脉冲；私聊成长通知 |

### 母体里程碑反馈

母体触发特定事件时，通过私聊 actionbar/title 收到反馈，**不广播给幸存者**，保持紧张感的同时让母体玩家感受到成长节奏：

| 事件 | 反馈（仅母体可见） |
|---|---|
| 成长 I 触发（T+5:00） | actionbar：`§4▲ 力量在增长 §8(+5 HP / 感知 +4)` + sound `ambient.cave` |
| 成长 II 触发（T+8:00） | actionbar：`§4▲ 爪牙更加锋利 §8(攻击加速 / 嚎叫增强)` + sound `ambient.cave` |
| 成长 III 触发（T+11:00） | actionbar：`§4▲ 完全进化 §8(+10 HP / 感染者脉冲)` + sound `entity.wither.ambient` |
| 首次成功感染（转化第 1 人） | title：`§4你的族群扩张了` + sound `entity.warden.roar`（仅母体） |
| 转化第 3 人 | actionbar：`§4同类已遍布岛上` |

> 设计意图：母体全程视野受限、信息最少，里程碑反馈让母体感知自身成长节点，同时可用这些节点调整进攻节奏——成长 II 后是发起大规模围攻的最佳时机。

### 普通感染者生命体系

| 项 | 数值 |
|---|---|
| HP | 与转化前一致（默认 20）|
| 护甲 | 0（除非生前是船长/海军陆战队员则保留装备） |
| 脱战回血 | 1 HP/3s |
| 复活 | 母体存活时，死亡 → 25–30 秒后在母体附近 8–16 格复活，空手 + 短暂无敌/虚弱 |
| 母体死亡后 | 不再复活；死亡感染者留在死亡锁定状态 |
| 阵营败北 | 母体死亡且所有感染者全灭 |

### 武器层级

| 类别 | 名称 | 来源 | 伤害 | 备注 |
|---|---|---|---|---|
| 基础近战 | 铁斧 | 全员开局 | 2 心/挥（攻速 0.9） | 默认武器 |
| 进阶近战 | 铁剑 | 海军陆战队员/船长/机修工开局；物资箱稀有 | 2.5 心/挥（攻速 1.6） | 战斗职业 |
| 远程 - 手枪 | M-7 半自动手枪 | **全员开局**（手枪 + 8 发）；海军陆战队员开局 24 发；物资箱补充弹药 | 3 心/发，对母体 2 心 | 8 发弹匣，2 秒装填，有效射击间隔 0.4s |
| 远程 - 信号枪 | 信号弹手枪 | 实验室稀有 + 物资 | 1 心 + 火焰 | 1 发，标记目标 5 秒 + 燃烧 3 秒 |

#### 手枪设计要点

- M-7 是独立手枪系统：玩家体感为**右键射击**，空匣或潜行右键进入装填；不使用原版弩伤害、原版弩装填或一发一装填规则结算
- 当前 demo 命令使用 `minecraft:sugar` + `item_model="ie:glock_gun"` + `consumable.consume_seconds=0` 验证右键即时开火和 `ie:gunshot` 枪声；这只是框架样例，不限制最终载体必须是 sugar
- 最终实现应抽成"手枪适配层"：任意稳定右键载体都可以，只要能承载枪模型/枪声、识别 `custom_data.weapon = "pistol"`、记录弹匣并把输入交给手枪玩法层；不得使用原版弩伤害和一发一装填规则
- **弹匣 8 发**：连续射击共 8 发后必须装填
- **装填 2 秒**：装填期间无法射击但可移动，体感接近真枪而不是传统拉弓/蓄力远程
- **有效射击间隔 0.4 秒**：框架输入冷却是 0.2 秒，但实际扣弹/伤害结算由玩法层限制为 0.4 秒，避免全员手枪变成高射速对枪
- **子弹（Item: `iron_nugget` 自定义命名"9mm 弹药"）**：开局弹药用于自保；物资箱提供额外补给，约 4–7 人局 +15 发 / 8–12 人局 +25 发 / 13–20 人局 +40 发
- **全员开局自带 1 把手枪 + 8 发**，保证每名幸存者都有最低限度反抗能力；海军陆战队员开局 24 发
- **对母体伤害**: 手枪框架直接按目标类型结算，普通目标 6 damage，母体 4 damage（再受母体护甲/抗性影响）
- **击杀母体需要**: 约 24–35 发实际命中 + 控制配合；母体死亡不复活，但幸存者还需要清理剩余感染者 → 单人无法靠开局弹药稳定清剿

### 关键平衡保护

- 全员开局手枪提供安全感，但开局弹药只有 1 个弹匣；开枪是"争取距离/救人/打断追击"，不是主胜利路径
- 母体**自带护甲、抗性和手枪目标系数**：手枪对母体是削弱后的专门伤害，不套用原版远程武器伤害
- 母体随时间成长，越拖越擅长追踪、召集感染者和维持压迫
- 子弹/烟雾/闪光是**稀缺消耗品**: 物资箱配置为"一局总量约够全队 2 次正面遭遇"
- **感染需要叠压**: 单次命中只增加污染值，母体必须创造连续追击或把目标逼进孢子区，才能真正触发感染期
- **队友间无 PvP**: 幸存者互不伤害；感染期玩家仍是幸存者，不会因为误击制造硬证据
- **母体不能无脑换血**: 母体死亡后不复活，并会切断感染者复活能力

### 战斗节奏样本

> "三人正在修信号塔，母体扑出。Marine 反手压制射击减速母体，工程师丢电池继续修，运动员滑铲远遁后绕回侧翼丢烟雾弹掩护撤离。母体咬中厨师一次，厨师的 actionbar 显示孢子污染升高，但尚未进入感染期。母体试图二次贴身，船医和 Marine 合力掩护厨师撤出污染区，污染值开始衰减。母体怒离，5 秒后任务进度 +1。"

这是设计目标的"教科书回合"——所有人都在用工具和位置，没有人在"对枪"。

## 七、任务系统

### 主任务：呼叫直升机

#### 修复信号塔

- 地图唯一信号塔（`signal_tower` marker）
- 修复阶段按人数缩放（默认 5 段），每个阶段消耗 1 根**线缆**
- 操作: 持有线缆 + 站在修复点 + 长按右键 5 秒 → 进度 +1
- 视觉: bossbar「信号塔修复 [▰▰▱▱▱]」全员可见
- 修复中受到伤害、离开范围或松手会打断当前阶段；已完成阶段不回退
- 感染者靠近信号塔只制造威胁和站位压力，不自动回滚已完成进度
- 完成 = 信号塔 LED 亮起 + 全图广播

#### 启动备用发电机

- 地图 2–3 个发电机（`generator` marker），任修一个即可
- 收集**燃料电池**并右键发电机投入；小人数局 2 块，标准局 3 块
- 燃料投入不可被感染者偷走；发电机过载熄火只中断运行，不移除已投入燃料
- 投满燃料后进入 10 秒预热；预热完成后进入稳定运行倒计时
- 稳定运行期间默认维持 60 秒；倒计时完成 → 视为发电完成
- 感染者 / 母体靠近发电机不会一脚归零，而是暂停稳定倒计时并积累「过载」
- 幸存者靠近并互动可降低过载；过载满时发电机熄火并进入故障状态，幸存者维修清空过载后重新预热，不需要重新投入燃料电池
- 这个设计让感染者破坏成为持续施压和占点争夺，而不是瞬间抹掉幸存者前功

#### 完成 → 直升机

- 信号塔 + 发电机都完成 → 触发 **Dawn Sequence**，世界时间随直升机倒计时逐渐推进到日出
- Dawn Sequence 开始时启动 90 秒直升机倒计时；直升机不是等固定时间天亮，而是被玩家修好的信号"叫醒"
- 直升机抵达时天色正好破晓，旋翼声和日出共同构成主线撤离的高潮
- 倒计时开始时广播随机降落点（4 个 `heli_pad` 中随机 1 个）
- 直升机使用 Animated Java 模型 `animated_java:helicopter/summon`，模型 root 标记为 `entity.helicopter`
- 倒计时最后 5 秒直升机从远处高空飞入；落地后开启 60 秒登机窗口
- 登机采用覆盖直升机整体的 `interaction` 判定，玩家右键机身范围 = 上机；模型本体只负责视觉，不承载骑乘
- 幸存者右键直升机后获得 `state.boarding` 并进入旁观等待起飞；感染者无法登机
- 母体伪装上机进入 8 秒扫描，扫描未被识破则触发伪装结局
- 直升机起飞动画先垂直升空，再向机头方向飞离；飞离结束后清理模型并进入撤离结算

### 副任务

#### 轮船维修（`ship_dock`）

- 收集船舶部件：螺旋桨、燃油泵、舵机连杆、启动电瓶、锚机绞盘
- 部件数量按人数缩放：4 人局 3 件（螺旋桨、燃油泵、舵机连杆）；5–7 人局 4 件（加启动电瓶）；8 人以上 5 件（再加锚机绞盘）
- 部件位置: 海岸边沉船残骸、岩礁、丛林深处、海风号原地、营地；每个位置承担不同风险：岩礁开阔易暴露、丛林易伏击、海风号距离近但适合埋伏、营地可顺手补给、沉船残骸提供轮船路线的视觉锚点
- 携带至船坞，手持船舶部件长按右键约 1 秒投入；本局所需部件全部投入后才进入船体修复阶段
- 玩家站在船坞 = 进度自然 +1/s；工程师被动提供额外修复效率；机修工对轮船修复 +30%；微型电池可让船坞成为短时间高速抢修点
- 多人可叠加，但有效修复上限约为 4 倍，避免大人数局瞬间修满、感染阵营没有争夺窗口
- 普通感染者站船坞 = 进度 -1/s；母体站船坞 = 进度 -2/s；设计目标是争夺/拖慢而不是单人瞬间抹掉幸存者成果
- 进度满 = 船只启动 30 秒登船窗口，并生成船舱 `interaction`；幸存者右键登船，感染者不能登船
- 轮船不需要等天亮；它的沉浸点是摸黑抢修、听着引擎咳嗽声离岸
- 注意: 船**不会等迟到**，30 秒后未上 = 留岛

#### 实验室（`lab_entrance`）

- 入口需「主任笔记」（`loot_keynote` 5 个候选位置随机 1 处刷出）
- 进入后地下迷宫，沿途 4 名「感染研究员」（高血量僵尸）
- 击杀每名研究员 → 掉落「员工身份卡碎片」(1/4)
- 4 张碎片到 `lab_terminal` → 长按右键 10 秒合成 → 解锁潜艇舱门
- 潜艇位于 `lab_sub`，玩家上座 → 45 秒倒计时撤离
- 感染者**不能进潜艇**（同直升机判定）
- 风险: 实验室内孢子浓度高，每 10 秒扣 0.5 心（除非有"防毒面具" — 实验室稀有掉落）

### 隐藏任务

#### 毁灭岛屿（彩蛋路线）

**触发条件**（必须全部满足才能在自爆装置交互）:
1. 持有 3 份「普罗米修斯文件」（从 5 个 `loot_keynote` 隐蔽候选点中固定刷出 3 份；位置难找，但单局不应随机无解）
2. 信号塔修好（保证有外界知情）
3. 实验室深处自爆终端（`island_bomb` marker）已激活

**激活流程**:
- 一名持有 3 份文件的幸存者走到自爆终端
- 长按右键：持有防毒面具时 **15 秒**，否则 **30 秒**；孢子浓度伤害不中断进度，**只有受到玩家攻击才归零**
- 激活后全图广播：「**W-7 自销毁系统启动，3:00 倒计时**」
- 自爆路线不需要等天亮；倒计时结束时直接结算毁灭岛屿
- 3 分钟内任意撤离方式逃出岛屿的人 → 该方判胜利

**胜利计算**:
- 至少 1 名幸存者在自爆倒计时结束前撤离 = 幸存者+岛屿毁灭，**Real Ending**
- 自爆完成时岛上还有人（含母体）= 全员死亡并转化失败，但幸存者方仍然胜（病毒被毁）
- 母体如果使用伪装试剂上了直升机 → 仍触发母体彩蛋（不会被自爆覆盖）

#### 母体伪装（母体彩蛋路线）

**触发条件**:
- 母体单独到实验室冷库（`lab_disguise` marker，藏在感染研究员区深处）
- 持有「员工身份卡碎片」x 2（仅母体可拾取，与幸存者所需的 4 张不冲突——是不同物品）
- 在冷库右键终端 → 获得「伪装试剂 X-7」

**使用**:
- 服用后 90 秒内母体对所有玩家显示为「幸存者」状态（标签变更，glowing 关闭，骨架显示恢复）
- 90 秒内成功上直升机 / 船 / 潜艇并通过 8 秒登载扫描 → **母体彩蛋胜利**
- 登载扫描期间全员收到一次模糊提示「生物识别出现异常」，不显示玩家名
- 通用反制：扫描 8 秒内任意幸存者攻击或重新右键直升机复核可打断母体登载，但不会直接暴露姓名
- 职业反制：若 8 格内病毒学家使用检测剂，伪装立即破裂，母体被击退并暴露 15 秒；否则扫描通过
- 90 秒过期未上交通工具 → 暴露 + 失败
- 注意: 这是母体**专属胜利路线**，与"感染所有人"并列。它允许戏剧性偷渡，但给幸存者留下一个短暂、需要职业配合的反制窗口

## 八、六个结局

### 1. 直升机 — 幸存者标准胜

- **触发**: 信号塔 + 发电机修好 → 动态破晓随 90 秒倒计时推进 → 直升机在日出时到达
- **判胜条件**: 至少 1 名幸存者上机
- **特别**: 上机时如有母体伪装在内 → 触发结局 5（伪装结局）

### 2. 轮船 — 幸存者次胜

- **触发**: 收集并投入本局所需船舶部件 + 修复进度 100%
- **判胜条件**: 30 秒登船窗口内至少 1 名幸存者右键登船

### 3. 实验室潜艇 — 幸存者隐藏路线

- **触发**: 4 张身份卡 + 潜艇启动
- **判胜条件**: 45 秒倒计时内至少 1 名幸存者上潜艇
- **特别**: 实验室死亡风险高，是高难度路线

### 4. 毁灭岛屿 — 中立胜利（真结局）

- **触发**: 3 文件 + 信号塔 + 自爆装置激活 + 自爆倒计时结束前有人撤离
- **判胜条件**: 至少 1 名幸存者撤离 → 幸存者方胜（包括自爆倒计时内被炸死的玩家也算赢）

### 5. 母体伪装 — 母体彩蛋胜

- **触发**: 母体服用伪装试剂 X-7 后 90 秒内上交通工具
- **判胜条件**: 仅母体撤离即胜（其他幸存者哪怕也撤离了，结局动画仍是这个）

### 6. 病毒变异 — 母体默认胜（Bad End）

- **触发**: 15:00 时间到 + 没有任何幸存者成功撤离
- **判胜条件**: 时间到时无幸存者已撤离 → 母体胜
- **特别**: 全员强制感染期 + 20 秒后转化结算

### 结局优先级

如果同时满足多个结局，按优先级触发:

```
母体伪装已通过登载扫描 > 毁灭岛屿真结局 > 直升机/轮船/潜艇 > 病毒变异
```

例如自爆已激活、直升机也到达：普通幸存者撤离按毁灭岛屿真结局结算；但母体若已在任意交通工具上通过 8 秒伪装扫描，则优先触发母体伪装结局。未通过扫描的伪装状态不会覆盖自爆结局。

新玩家在开局 2 分钟内容易"什么都不知道"——不知道技能怎么用、不知道孢子是什么、不知道任务在哪。以下设计专门针对首次游玩：

## 十一、训练模式与结算观战

### 训练模式 (`function escape_island:training/start`)

- 单人加载，适用于摸熟职业 / 测试技能
- 自动给所有 10 套职业道具（可切换） + 母体技能（debug 标签）
- 任务点开放无限刷新
- 时间锁定不前进
- 无胜负、无结局

### 结算观战模式

- 进入条件:
  - 主动放弃（菜单中 "/function escape_island:player/give_up"）
  - 直升机 / 船 / 潜艇撤离成功 → 在结算屏蔽期间进入观战，不再参与场上交互
  - 整局结算完成后所有人进入观战 / 结算空间
- 权限: gamemode spectator，可自由飞行，看所有玩家
- 限制: 不能与场上玩家交互、聊天受限于"全员公屏"或"观众频道"（自定义命令实现）
- 原则: 对局中死亡不进入旁观者，也不能自由飞行；除主动放弃外，早死玩家会先倒地孢化，再转化为感染者继续参与

### 复盘 (`function escape_island:debug/show_state`)

任意阶段可由观众或房主查看:
- 当前阶段 / 时间余量
- 母体玩家名（仅对 OP 显示）
- 各任务进度
- 已感染玩家列表
- 已死亡玩家列表

## 十二、缩放规则（4–20 人弹性）

| 玩家数 | 母体配置 | 感染期时长 | 信号塔阶段数 | 部件数 | 身份卡碎片 |
|---|---|---|---|---|---|
| 4 | 1 | 55 秒 | 3 | 3 | 3 |
| 5–7 | 1 | 50 秒 | 4 | 4 | 3 |
| 8–12 | 1 | 45 秒 | 5 | 5 | 4 |
| 13–16 | 1 | 40 秒 | 6 | 6 | 4 |
| 17–20 | 1 母体 + 1 潜伏宿主 | 40 秒 | 7 | 7 | 5 |

### 小人数局母体强化

4–7 人局母体初始 HP 提升至 **70**（标准局 60），以补偿幸存者数量少、协作能力弱对母体的不利影响。成长上限同样上移 +10（成长后最高约 85）。

### 小人数局职业池（4–7 人）

4–7 人局分配职业时，**船医**必须出现在非母体幸存者中。实现上：先确定母体，再检查剩余幸存者职业；若没有船医，则优先把最后一名非母体普通职业替换为船医。若原本抽到船医的人后来成为母体，也必须在剩余幸存者中补 1 名船医。

其余职业从 10 个职业中完全随机；8 人及以上局使用完整随机池，不保证特定职业出现。

### 潜伏宿主（17–20 人局）

- 开局额外隐秘预选 1 名潜伏宿主，T+2:00 仅收到一句模糊私聊「你觉得伤口在发热」，不会获得母体道具
- 潜伏宿主/次级母体后续重新设计；新版主母体不可复活，因此潜伏宿主不能在主母体死亡后自动顶替母体
- 暂定大人数局仍可预选潜伏宿主，但觉醒条件、是否拥有母体技能、是否影响清剿胜利都需要单独重审

> 数值具体调参见 [BALANCE.md](BALANCE.md) 的"缩放函数"章节。

## 十三、天赋系统

新版天赋系统废弃旧的"6 选 2 永久数值加成"方案，改为 **人格牌组**：

- 像《黎明杀机》一样，每名玩家赛前带入一组可形成打法的 perk
- 像《第五人格》一样，天赋被分成救援、修理、牵制、情报四条人格路线，并有强力核心人格
- 每局额外抽取 1 张不可预知的 **命运牌**，让同一套构筑也会出现不同局内节奏

旧方案的问题：

- 天赋太少，6 选 2 很快会被玩家解出固定答案
- 多数效果是永久数值，例如移速、夜视、伤害，强但不戏剧化
- 天赋没有冷却、代价和触发窗口，玩家缺少"我现在要不要交牌"的判断
- 母体替换只是把幸存者数值换成母体数值，缺少隐藏身份玩法里的反转感
- 随机性主要依赖职业随机，没有让同一职业在不同局里产生足够变化

### 设计意图

- **构筑感**：玩家赛前选择自己的打法倾向，例如救援位、修理位、牵制位、侦察位
- **局内戏剧性**：强天赋多为条件触发，带冷却、消耗或副作用，制造关键时刻
- **反身份博弈**：同一张人格牌有幸存者面和母体面；被选为母体后自动翻面，不暴露赛前选择
- **随机变化**：命运牌每局随机，不可指定；它不是核心强度来源，而是让计划出现偏差和惊喜
- **反最优解**：限制同类叠加和永久速度/伤害，避免所有人都选同一套

### 选择流程

```
Pre-game 大厅
  ↓
右键天赋 NPC
  ↓
选择 1 个核心人格 + 2 个支线人格
  ↓
开局时系统随机补 1 张命运牌
  ↓
分配职业 / 觉醒母体
  ↓
幸存者保留正面效果；母体玩家的人格牌全部翻到母体面
```

### 构筑规则

每名玩家最终拥有 4 个天赋槽：

| 槽位 | 来源 | 作用 |
|---|---|---|
| 核心人格 | 玩家选择 1 个 | 类似第五人格终极人格，定义这局主要打法 |
| 支线人格 A | 玩家选择 1 个 | 提供中等强度的条件效果 |
| 支线人格 B | 玩家选择 1 个 | 与职业或路线形成组合 |
| 命运牌 | 开局随机 1 个 | 每局变化源，轻量但会改变选择 |

限制：

- 同一名玩家最多携带 1 个牵制位移类天赋
- 全局修复速度加成受任务自身上限约束，不能靠多人堆天赋秒修
- 信息天赋只能给距离、方向、异常迹象，不能直接报出"谁是母体"
- 战斗天赋偏向拖延、撤退、打断，不提供稳定击杀母体的硬增伤
- 命运牌不允许成为构筑核心；它只能改变局部路线、资源或一次性机会

### 四条人格路线

| 路线 | 适合玩家 | 玩法关键词 |
|---|---|---|
| 救援 | 船医、神父、船长，以及愿意跟队的人 | 护送、救感染期队友、倒地前争取时间 |
| 修理 | 工程师、机修工、通讯员 | 抢任务窗口、降低打断损失、路线推进 |
| 牵制 | 运动员、海军陆战队员、船长 | 拉扯、断追、骗母体交变异 |
| 情报 | 通讯员、病毒学家、神父 | 判断路线、发现异常、制造团队共识 |

### 核心人格示例

核心人格强度高，但都有明显条件或冷却。它们应该制造"刚好活下来"、"刚好拖住"、"刚好抢完"这种局内记忆点。

| 核心人格 | 幸存者面 | 母体面 |
|---|---|---|
| **化险为夷** | 你治愈感染期队友、护送队友登上交通工具或在倒地孢化前靠近队友时，双方获得短暂速度/抗性，冷却长 | 首次让幸存者进入感染期后，短时间重置追踪节奏，鼓励母体继续压迫救援链 |
| **破窗余势** | 被母体或感染者命中后，若未处于疲劳，获得短暂加速，随后进入疲劳 | 命中刚脱离视线的目标后获得短暂追猎加速，帮助母体完成收割 |
| **临危专注** | 在修理点连续操作数秒未被打断后，短时间提高本人的交互效率；受伤立刻失效 | 母体破坏修理点时留下短暂腐蚀，幸存者需要重新争夺位置 |
| **旧讯号** | 完成一个任务阶段后，获得一次私有路线提示或异常方向提示 | 幸存者完成任务阶段时，母体获得模糊方位感和一次干扰通讯机会 |
| **孤注一掷** | 附近队友很少时，修理/投入/登船动作略快，但受到污染增加 | 单独行动的幸存者更容易被母体追踪，鼓励抓落单 |
| **回光返照** | 任意撤离路线开启时，清除自身迟缓/失明并获得短暂冲刺；单局一次 | 任意撤离路线开启时，母体变异冷却刷新，并获得一段终局追猎窗口 |

### 支线人格示例

支线人格比核心人格弱，更多是塑造习惯和微决策。

| 路线 | 支线人格 | 设计作用 |
|---|---|---|
| 救援 | **急救手法** | 治愈、解毒、自救后的抗污染窗口略长 |
| 救援 | **并肩而行** | 与感染期或倒地孢化队友靠近时，自己获得短暂抗性，但移动略慢 |
| 救援 | **最后留言** | 进入倒地孢化时给附近队友一个短暂异常方向提示 |
| 修理 | **稳手** | 任务读条被轻微位移打断时有一次缓冲 |
| 修理 | **备件意识** | 首次投入线缆、燃料或船舶部件后，私有提示下一个推荐路线点 |
| 修理 | **搜刮路线** | 首次打开物资点时更容易获得路线消耗品，而不是纯战斗物资 |
| 牵制 | **泥地步法** | 减速、陷阱、孢子云的持续时间略短 |
| 牵制 | **烟幕训练** | 自己受烟雾/闪光负面影响更短，投掷控场物更可靠 |
| 牵制 | **硬撑** | HP 低于阈值时首次受到非致命伤害，获得短暂抗性但进入长冷却 |
| 情报 | **疑心** | 有玩家长时间贴近你时获得心跳提示，不显示姓名和阵营 |
| 情报 | **地图记忆** | 访问过的关键点再次靠近时显示当前路线状态 |
| 情报 | **静默搜索** | 搜刮和阅读书页时声音/粒子更弱，适合偷偷走隐藏路线 |

### 命运牌

命运牌在开局投放后抽取。玩家不能指定，只能看到自己抽到了什么。

| 命运牌 | 效果方向 |
|---|---|
| **多余弹匣** | 开局额外获得少量 9mm 弹药 |
| **湿透地图** | 首次进入黑夜抢修期时获得一个最近任务点方向提示 |
| **旧钥匙** | 第一次长按任务交互的前 1 秒自动完成 |
| **船舱记忆** | 轮船路线相关交互略快，但实验室交互无加成 |
| **冷库印象** | 实验室高浓度孢子首次伤害被抵消 |
| **坏天气老手** | 第一次风暴/断电影响时间缩短 |
| **口袋绷带** | 第一次脱战后自动恢复少量生命 |
| **无线电回声** | 第一次环境事件触发时获得一个私有异常方向提示 |

命运牌的目标不是公平地增强每个人，而是让玩家每局临时调整计划：抽到船舱记忆的人更想推轮船，抽到冷库印象的人更愿意去实验室，抽到无线电回声的人会更适合抱团决策。

### 转化后的保留规则

- 普通感染者不再完整保留幸存者天赋，只保留"感染回声"
- 感染回声只保留原天赋约 30–50% 的强度，且偏向追击、干扰、复活节奏
- 这样可以保留"他生前是什么打法，转化后仍有影子"的趣味，但不会让强幸存者构筑在感染阵营变成双倍收益

示例：

| 幸存者构筑倾向 | 转化后的感染回声 |
|---|---|
| 救援 | 复活后短时间更耐打，但追击能力不强 |
| 修理 | 靠近任务点时破坏效率略高 |
| 牵制 | 复活后短时间速度略高，但持续短 |
| 情报 | 靠近幸存者时更容易收到模糊方向反馈 |

### 保存与重置

- 玩家选择存储为 `talent.core.*` 与 `talent.minor.*` tag
- 命运牌存储为 `talent.fate.*` tag，每局开始时随机写入
- 开局后 tag 伴随整个对局；转化时由 `talent/echo_on_infect` 生成感染回声 tag
- 母体觉醒时由 `talent/flip_mother` 把已选人格翻到母体面
- `game/start` 与 `game/settle` 清除所有 `talent.*` tag
