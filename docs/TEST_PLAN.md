## 一、测试哲学

| 原则 | 应用 |
|---|---|
| **每改一个数值，跑一次相关单测** | BALANCE 改完后 `test/perf_check` 必须 < 5ms |
| **每个里程碑结束，跑一次完整流程联机** | 至少 4 人，30 分钟，覆盖一条结局路线 |
| **不靠"运气没复现"过测** | 任何偶发 bug 必须能在 `test/full_simulation` 重现才算修复 |
| **优先调试模式快速验证** | 用 `tunable.debug=1` 把 15 分钟压到 3 分钟，提高迭代速度 |

## 三、单机自动化测试

### `escape_island:test/perf_check`

每次改代码后跑一次。在空房间召唤 20 个 ArmorStand 模拟玩家，调用主 tick 1000 次，输出平均 / 最大耗时。

```mcfunction
# 期望输出 (在控制台)
[escape_island:perf] avg=1.8ms / max=4.2ms / iterations=1000
```

阈值: avg < 3ms, max < 5ms。超过即性能回退，必须排查。

### `escape_island:test/spawn_dummies`

```
spawn 4 假玩家（armor_stand + team.human + 完整属性）到不同 `marker.spawn_island`
分配职业:
  dummy_1 → 船医
  dummy_2 → 工程师
  dummy_3 → 海军陆战队员
  dummy_4 → 通讯员
开局后等 2 分钟看母体随机选谁
```

### `escape_island:test/full_simulation`

模拟一整局（15 分钟压缩到 3 分钟，调试模式）:
- 0:00 开局
- 0:24 母体觉醒
- 0:36 进入黑夜抢修
- 1:40 信号塔 + 发电机完成，触发动态破晓和直升机倒计时
- 2:30 1 名假玩家上机 → 触发直升机结局

预期结果: 任何阶段都没有 mcfunction 错误，结局动画正确播放。

### `escape_island:test/regression_M2`

专门验证感染状态机:
1. 召唤 1 个 dummy，给 infected.mother
2. 召唤 1 个 dummy，给 team.human + role.doctor
3. mother 攻击 doctor 1 次 → 检查 doctor 的 `spore_load` 增加且未获得 `state.infected_period`
4. mother 再次攻击 doctor → 检查 doctor 获得 `state.infected_period`
5. 等 0.5 秒，doctor 用解毒针对自己（dummy 不能右键，用 `function skill:doctor/inject` 模拟）
6. 检查 `state.infected_period` 是否被清除，且获得短暂 `state.infection_resist`

每个 M2 修复后跑一次。

## 四、联机集成测试

### 4 人局基础测试

**前置**: 玩家 4 名进入服务器 / 单人开放局域网，全员有 OP（测试需要）。

**步骤**:

1. 房主 `/function escape_island:game/start`
2. 4 人被分散传送到不同 `marker.spawn_island`，每人收到职业道具
3. 等待 3 分钟（或 `tunable.debug=1` 加速）
4. 仅 1 人收到母体 tellraw（私聊询问每个人确认）
5. 母体故意攻击 1 名幸存者 → 全图 tellraw "丛林深处嚎叫"，被攻击者污染值正确增加
6. 母体连续攻击同一目标使其进入感染期，船医（如未死）使用解毒针 → 治愈成功，冷却显示 90 秒
7. 工程师/通讯员 → 修信号塔 + 发电机
8. 任务完成 → 直升机倒计时
9. 至少 1 人上机 → 直升机结局
10. 全员看到字幕 + 进入结算观战

**预期**:
- [ ] 全程无控制台报错
- [ ] 所有提示文本正确显示
- [ ] 母体身份 ≠ 直接被识别
- [ ] 至少 1 人撤离 → 幸存者方判胜
- [ ] 倒计时数字精准（误差 < 1 秒）

### 8 人局任务覆盖测试

**目的**: 验证副线路线和环境事件在更多人时不会卡死。

**额外检查**:
- [ ] 实验室 4 名僵尸正确刷出
- [ ] 身份卡碎片合成正常
- [ ] 潜艇结局触发
- [ ] 至少 2 次环境事件触发（断电、幻觉等）

### 12 人局完整结局测试

**目的**: 完整跑一遍所有结局（多局）。

每局指定不同结局触发方式:
- 局 1: 直升机
- 局 2: 轮船
- 局 3: 实验室潜艇
- 局 4: 毁灭岛屿（让 1 名玩家专攻文件 + 自爆）
- 局 5: 母体伪装（指定母体专攻伪装试剂）
- 局 6: 病毒变异（不让任何人完成任务）

每局结束后填写 [Bug 报告模板](#六bug-报告模板)。

### 20 人局压力测试

**目的**: 性能 + 平衡极限。

**额外检查**:
- [ ] 1 名主母体 + 1 名潜伏宿主被隐秘选中
- [ ] 潜伏宿主新版规则待定；确认不会在主母体死亡后自动顶替母体
- [ ] 主 tick < 5ms（用 `/perf start <duration>` 验证）
- [ ] 多个 bossbar 同时显示不冲突
- [ ] 所有 tellraw 在 20 人服务器上不延迟
- [ ] 直升机座位充足（4 个 heli_pad，每个最多坐 5 人）

## 五、性能基线

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 主 tick 平均耗时 | < 3ms | `/perf start 30` 然后查 `escape_island.tick` |
| 主 tick 峰值 | < 5ms | 同上 |
| 单 mcfunction 命令数 | < 1000 | 静态扫描 |
| Datapack 总 mcfunction 数 | < 200 | 文件计数 |
| Datapack 总大小 | < 5 MB | 文件夹大小 |
| 单局产生的 marker 实体数 | < 50 | `/data get @e[type=marker] count` |
| 单局产生的 display entity | < 100 | 同上 |
| 内存峰值（服务端进程） | 无明显增量 | 任务管理器对比开关游戏前后 |

## 七、回归测试套件

每次发版前必须全跑一遍。

### Quick Regression（10 分钟）

```
/function escape_island:test/perf_check
/function escape_island:test/regression_M2
/function escape_island:test/full_simulation
```

### Full Regression（半天）

- Quick Regression
- 4 人联机：直升机结局
- 8 人联机：实验室潜艇结局
- 12 人联机：毁灭岛屿结局

- Full Regression
- 6 种结局各跑 1 次
- 4/8/12/16/20 人各跑 2 次
- 设计师手工验收 BALANCE 数值
- 文档（特别是 README、MAP_GUIDE）从零跟一遍

完成 → 可以发布正式版本号 (1.0.0)。
