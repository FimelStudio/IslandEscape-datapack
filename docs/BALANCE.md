# BALANCE — 数值平衡表

所有可调数值集中在此。规则与玩法见 [GDD.md](GDD.md)。

## 平衡假设

| 局面 | 期望胜率 |
|---|---|
| 4 人局（1 母体 + 3 幸存者） | 母体 50% / 幸存者 50% |
| 8 人局（1 + 7） | 母体 45% / 幸存者 55%（人多了智斗优势放大） |
| 12 人局（1 + 11） | 母体 50% / 幸存者 50% |
| 20 人局（1 母体 + 1 潜伏宿主 + 18 幸存者） | 母体 50% / 幸存者 50%（延迟第二压力源补足） |

> 这些是设计目标，需要通过测试调参。BALANCE 中所有数值都是 v0.1 推断值，**首次联机后必然要回炉**。

> **设计约束**：M-7 不采用原版弩的一发一装填和原版弩伤害。当前命令只是 demo 参考，最终载体可以替换；弹匣、9mm 消耗、2 秒装填、阵营过滤和伤害必须由玩法函数结算。若采用会被消耗的载体，射击函数必须同 tick 替换/补回手枪，保证武器不丢失。

#### 击杀母体所需投入（更新后数值）

- 母体初始 60 HP（4–7 人局 70 HP），成长后最高约 75 HP（4–7 人局约 85 HP）；手枪对母体基础 4 damage，再受护甲/抗性影响
- 无脱战：约 24–35 发实际命中可击杀
- 有脱战回血（5 秒未受伤 → 1 HP/s）：必须持续压制，否则母体逐步恢复
- 母体死亡不复活，感染者失去复活能力；击杀母体是高风险高收益的清剿路线
- 综合：多人协力约需 4 个弹匣级别的资源 + 控制配合，且需要继续清理剩余感染者

#### 防御机制（防止纯枪战阵营）

- **全员开局枪，但弹药稀缺**: 每名幸存者至少有 8 发用于自保；额外弹药控制在"够两次正面遭遇"，避免变成纯枪战
- **PvP 间无伤**: 队友间无伤害（防止误击 + 心理攻击）
- **母体腐痕感知 + 吞噬 + 集群嚎叫**: 母体能追踪、抓单并召集团队，破解纯远射风筝策略
- **目标类型伤害系数**: 手枪框架对母体单独降伤害，避免原版远程伤害过高
