# BALANCE — 数值平衡表

所有可调数值集中在此。规则与玩法见 [GDD.md](GDD.md)。

## 平衡假设

| 局面 | 期望胜率 |
|---|---|
| 4 人局（1 母体 + 3 幸存者） | 母体 50% / 幸存者 50% |
| 8 人局（1 + 7） | 母体 45% / 幸存者 55%（人多了智斗优势放大） |
| 12 人局（1 + 11） | 母体 50% / 幸存者 50% |
| 20 人局（1 母体 + 1 潜伏宿主 + 18 幸存者） | 母体 50% / 幸存者 50%（延迟第二压力源补足） |

> 这些是设计目标，需要通过测试调参。BALANCE 中所有数值都是 v0.1 推断值，**首次联机后必然要回炉**。

### 分层撤离阈值

普通撤离路线（直升机 / 轮船 / 潜艇）按最终成功撤离的幸存者人数结算。达到阈值 = 完整幸存者胜利；低于阈值但有人撤离 = 惨胜 / 部分撤离。

| 玩家数 | 完整胜利撤离阈值 | scoreboard 建议 |
|---|---:|---|
| 4–7 | 1 | `tunable.escape_full_win_count = 1` |
| 8–12 | 2 | `tunable.escape_full_win_count = 2` |
| 13–16 | 3 | `tunable.escape_full_win_count = 3` |
| 17–20 | 4 | `tunable.escape_full_win_count = 4` |

结算输出建议同时记录:
- `escaped_survivors`: 成功撤离人数
- `escape_result`: 0=无人撤离 / 母体胜，1=惨胜，2=完整胜利，3=真结局，4=清剿胜利

- **母体腐痕感知 + 吞噬 + 集群嚎叫**: 母体能追踪、抓单并召集团队，破解纯远射风筝策略
- **目标类型伤害系数**: 手枪框架对母体单独降伤害，避免原版远程伤害过高

## 十一、天赋系统

新版天赋为 **人格牌组**，不是旧的 6 选 2 永久数值加成。每名玩家赛前从已解锁牌池中选择 1 个核心人格 + 2 个支线人格，开局随机获得 1 张命运牌。生涯系统只解锁更多可选牌和预设栏位，不增加天赋槽或永久数值。

### 选择流程

```
Pre-game 大厅 → 天赋 NPC → 选 1 核心 + 2 支线 → 确认
                                         ↓
                              开局随机补 1 张命运牌
                                         ↓
                         母体觉醒时人格牌翻到母体面
```

### 全局限制

- 每人最多 1 个核心人格、2 个支线人格、1 张命运牌
- 位移/追逐类天赋共享 `talent.exhaustion`，默认 45 秒
- 救援类强触发共享 `talent.rescue_cd`，默认 120 秒
- 情报类强触发共享 `talent.info_cd`，默认 90 秒
- 任务加速在所有职业、天赋、电池叠加后仍受任务自身上限约束：信号网络和轮船全队最高约 2.5 倍
- 天赋不能直接显示母体姓名；最多显示异常方向、距离段、事件提示
- 命运牌强度约等于半个支线人格，不能成为必选核心

### 母体翻面与感染回声

母体觉醒时：

- 移除 `talent.core.*` / `talent.minor.*` 的幸存者生效逻辑
- 根据同名人格应用母体面逻辑
- 命运牌不翻面，但部分命运牌在母体身上改为猎手资源，例如 `extra_mag` 变为开局腐痕感知冷却 -15s

普通感染者转化时不完整保留天赋，只获得感染回声：

| 原路线 | 感染回声 |
|---|---|
| 救援 | 复活后抗性 I +5s |
| 修理 | 靠近任务点时破坏/干扰效率 +15% |
| 牵制 | 复活后速度 I +3s |
| 情报 | 每 45s 获得最近幸存者距离段提示一次 |

感染回声只保留 30–50% 强度，避免强幸存者构筑转化后双重收益。

### 保存与重置

- 玩家选择存储在 `talent.core.*`、`talent.minor.*`
- 命运牌存储在 `talent.fate.*`
- 冷却使用 `talent.exhaustion`、`talent.rescue_cd`、`talent.info_cd`、`talent.trigger_cd`
- 感染回声使用 `talent.echo.*`
- `game/start` 重置时清除所有 `talent.*` tag，并重置相关 scoreboard
- `game/settle` 清除所有 `talent.*` tag

### 技术实现要点

- 大厅天赋选择：tellraw 按钮 + 记分板追踪已选数量
- 天赋 NPC：`marker.talent_npc` 处 interaction 实体，右键打开菜单
- 命运牌抽取：`game/start` 后调用 `talent/roll_fate`
- 母体翻面：`_make_mother` 末尾调用 `talent/flip_mother`
- 感染回声：`infection/turn` 末尾调用 `talent/echo_on_infect`
- 效果接入：在感染、任务、撤离、战斗 tick 中按 tag 条件触发，而不是全靠永久属性

## 十二、生涯与 MVP 系统

生涯系统只提供长期目标、展示、称号、徽章、天赋选择范围和预设栏位，不提供永久战斗数值。

### 生涯等级

| 生涯等级 | 累计 XP | 解锁 |
|---:|---:|---|
| 1 | 0 | 基础天赋池、基础档案 |
| 3 | 300 | 基础称号选择 |
| 5 | 700 | 第 2 套天赋预设 |
| 8 | 1300 | 入门专精天赋解锁 |
| 10 | 1800 | MVP 展示边框 |
| 15 | 3200 | 第 3 套天赋预设 |
| 20 | 5200 | 高级称号 / 赛季徽章展示 |
| 30 | 10000 | 纯展示奖励，不加局内强度 |

推荐公式：Lv.30 后每级所需 XP 增量继续提高，但只给展示奖励。

### 每局生涯 XP

| 来源 | XP |
|---|---:|
| 完整胜利 | +100 |
| 惨胜 / 部分撤离 | +70 |
| 阵营失败但坚持到终局 | +40 |
| 真结局参与 | +120 |
| 清剿胜利参与 | +100 |
| 全局 MVP | +50 |
| 阵营 MVP | +35 |
| 高光奖项 | +20 |
| 玩家点赞 | +5 / 票，上限 +25 |

每局基础生涯 XP 建议软上限为 220；真结局可突破到 260。

### 专精 XP

| 专精 | 主要来源 | 每局软上限 |
|---|---|---:|
| 救援 | 解毒针、备用疫苗、厨师暂停转化、护送感染期队友、靠近倒地孢化队友 | 120 |
| 修理 | 修塔、修船、发电机、投入部件、实验室终端、自爆终端 | 120 |
| 牵制 | 被母体 / 感染者追击后存活、控制猎手母体、用烟雾/闪光/陷阱救人 | 100 |
| 情报 | 通讯扫描、隔离扫描、发现异常、给出路线提示、反制伪装 | 100 |
| 感染 | 污染、感染期、转化、任务点压制、守撤离点、保护母体 | 130 |

专精等级推荐按单独 XP 升级：

| 专精等级 | 累计专精 XP | 用途 |
|---:|---:|---|
| 1 | 0 | 基础路线 |
| 2 | 150 | 解锁 1 张支线人格 |
| 3 | 400 | 解锁路线称号 |
| 4 | 800 | 解锁 1 张核心人格或命运牌变体 |
| 5 | 1400 | 解锁高级徽章展示 |

|---|---:|

### 高光奖项

| 奖项 | 判定 |
|---|---|
| 最佳救援 | `match_rescue_score` 最高 |
| 最佳修理 | `match_repair_score` 最高 |
| 最佳牵制 | `match_kite_score` 最高 |
| 最佳情报 | `match_info_score` 最高 |
| 最佳猎手 | 母体玩家 `match_infect_score` 最高且有转化 / 感染期贡献 |
| 最佳感染者 | 普通感染者 `match_infect_score` 最高 |
| 绝境生还 | 感染期倒计时 ≤5 秒时仍成功撤离 |
| 岛屿之心 | 参与真结局关键步骤 |

### 天赋解锁关系

| 条件 | 解锁 |
|---|---|
| 默认 | 每条路线基础 1 个核心人格 + 2 个支线人格 |
| 救援专精 Lv.2 | 额外救援支线人格 |
| 修理专精 Lv.2 | 额外修理支线人格 |
| 牵制专精 Lv.2 | 额外牵制支线人格 |
| 情报专精 Lv.2 | 额外情报支线人格 |
| 感染专精 Lv.2 | 额外母体面 / 感染回声人格 |
| 任一专精 Lv.4 | 解锁该路线 1 个高级核心人格或命运牌变体 |
| 生涯 Lv.5 | 第 2 套天赋预设 |
| 生涯 Lv.15 | 第 3 套天赋预设 |

限制：

- 天赋槽数量不随生涯提升
- 已解锁天赋的数值不随生涯提升
- 未解锁玩家仍可使用完整基础池，不会缺少关键职责

### 防刷规则

| 规则 | 说明 |
|---|---|
| 同目标救援递减 | 90 秒内反复救同一玩家，MVP / XP 递减 |
| 同任务点刷分限制 | 同一任务点来回中断不重复给完成奖励 |
| 污染 / 治疗互刷限制 | 同两名玩家之间的污染-治疗循环有计分冷却 |
| 点赞上限 | 玩家点赞每局最多提供 +25 XP |
| 失败局保护 | 失败方仍给贡献 XP，但 MVP 加成略低 |
| 旁观限制 | 结算观战不再累积 match 分 |
