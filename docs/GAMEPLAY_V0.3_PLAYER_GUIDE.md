# 海岛逃生 v0.3：玩家速读

这是拟议 v0.3 玩法的简明说明，尚未在当前数据包启用。精确规则见[完整规格](GAMEPLAY_V0.3_SPEC.md)；本页不展开隐藏彩蛋解法。

## 一局要做什么

**找工具和模块 → 恢复供电 → 修好通讯并求救 → 前往停机坪 → 真正登机离岛。**

直升机每局都有。开局状态板会告诉你船、潜艇是否能修复；它们是额外机会，共用人类的逃生资格，不要求特定职业。

最低 4 人、推荐 6 人；设计覆盖 4–12 人。4–8 人有一名母体，9–12 人有两名。标准局从八个职业的随机三个候选中选一，能够重抽一次；没有医师也能救人，没有工程师也能修理。

## 谁是敌人

开始时所有人都像普通研究人员。约 90 秒后，母体私下觉醒，可以先和你一起做真正的任务，再选择显形袭击。

显形后的母体可以被击杀，也不会再变回受友军保护的人类。最后一名母体死亡，普通感染者失去复活能力；清理全部感染威胁后，仍在岛上的人可以清剿获救。

普通感染者是转化后的玩家。他们继续追击、封路与阻止撤离；母体还活着时，死亡后可以等待回场。

## 倒地和感染怎么救

| 状态 | 需要什么 |
|---|---|
| 受伤 | 绷带或护理恢复生命 |
| 倒地 | 队友连续扶起 3 秒；可以先拖到掩体 |
| 感染期 | 使用解毒剂，感染期结束前仍是队友 |
| 同时倒地与感染 | 看两个剩余时间，选择先解毒或先扶起 |
| 已经孢化或转化 | 无法变回人类，准备迎接新的敌人 |

扶起不等于解毒，解毒不等于扶起。基础操作人人会；医师、搜救员和强化提供额外帮助。每段人类生命最多两次可救倒地，重复重伤会缩短窗口。

## 怎样分工

发电机需要的模块在不同区域，维修有两个可用端口。一个人送模块时，其他人可以准备通讯、找药或观察通路；修好的阶段不会因为敌人站在旁边就清零。

八个职业分别擅长：维修、医疗、护卫、搜索、搬救、补给、通讯与污染防护。短时分组可以加快准备，遇险时要留下会合和支援办法。

你会获得两次三选一强化：母体觉醒时一次，恢复供电或到 6 分钟时再一次。可以晚点选择，打开面板不会暂停或保护自己。转化后强化换成对应的感染效果，不额外赠送一套新卡。

## 三种离岛方法

- **直升机：** 恢复供电、修通讯并求救。信号弹可以提前指定落点；没有引导时，机组会选择一个可达停机坪并公布。到达后停留有限时间。
- **轮船：** 找发动机组件和燃料，送到离岛港口维修。不必恢复主岛供电，可经维护栈道或手动开桥，但搬运和过桥会有风险。
- **潜艇：** 恢复供电，找到松狮并护送到地下海，由他完成虹膜授权。护送路上可能需要保护和救援。

登载需要检疫，登记后仍可能遇袭；交通工具真正离开时，仍符合条件才算成功。感染期未到期可以撤离，倒地者须先扶起。提前乘船的人不会立刻结束仍在岛上的人的游戏。

## 怎样算赢

个人成功与整局营救规模分别记录。六人单母体局有五名原始幸存者，累计救出三人达到完整营救；四人局需救出三名原始幸存者中的两名。不同路线的撤离人数可以累计。

没达到完整营救也会记录每个成功离岛的人；清剿是独立胜利。感染方争取阻断更多人撤离，转化后的贡献仍有意义。少数对局还有隐藏线索，它们不属于每局必须完成的目标。

全局封锁时间有限。不要把“已经登记登机”当作获救，也不要把所有希望都押在还没有找到的彩蛋上。
