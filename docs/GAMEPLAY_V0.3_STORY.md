# 海岛逃生 v0.3 R1：背景、因果与叙事落点

日期：2026-11-03。配套[完整玩法规格](GAMEPLAY_V0.3_SPEC.md)。这是开发用完整背景，含隐藏彩蛋剧透；不能把全文当作玩家开局介绍。

## 1. 故事定位

一座以海洋药物和感染控制为名运行的研究岛，在一次夜间事故后进入封锁。普通工作人员醒来时，只知道电力中断、外部通讯失效，以及很快会有一轮彻底封航。他们必须恢复设施、取得外部接应，并决定能信任谁。

玩家不是被赋予不同逃生资格的船员与科学家，而是同一设施里的不同岗位。职业说明自己擅长什么，公共应急权限说明为什么任何人都能参与撤离。重复职业来自同一岗位的多名值班人员，不需要假设岛上每种专业永远只有一个人。

每局是同一场事故的不同可能发展，角色、受损状态、供给和结局会变化；不建立“大家每天失忆再死一次”的强制时间循环设定。前传关系通过分支结局衔接，不宣布玩家每次成功都不算正史。

## 2. 事故之前发生了什么

1. 衔尾蛇生物科技接管 Site-7。这里地形封闭，有现成地下设施与海上运输条件，适合保密研究。
2. “普罗米修斯计划”研究能够修复组织的共生病原，试图以一个稳定核心协调受感染组织。公开项目是创伤医疗，秘密目标是保留感染组织的服从与再生能力。
3. 部分试验失控，感染网络开始把活人当作扩张与维护自身的资源。公司没有及时撤空设施，而是加强隔离，并对暴露人员使用暂时抑制剂。
4. 夜间事故破坏电网和通讯。应急程序把员工集中隔离在宿舍，部分人经历急救镇静，醒来后记忆不完整；不要求所有人完全失忆。
5. 外部封锁单位已安排封航，岛上自动广播给出剩余窗口。失去通讯时，他们不会知道哪些登载区仍能使用，也不会盲目深入设施搜寻。

玩家不需要先读懂公司阴谋才能开局。第一分钟只传达：自己在哪、为什么危险、下一步做什么。

## 3. 为什么有人变成母体

母体宿主在事故前已经受到特殊暴露，抑制剂让其暂时保持普通工作人员状态。开局的秘密觉醒是抑制失效、感染核心接管宿主的时刻；大厅抽选是多人游戏分配角色的方法，不是剧情里有人现场掷骰决定谁感染。

隐藏阶段的身体仍保留人类外观和操作能力，可以真实地搬运、护理和修理。感染核心会利用这些能力维持伪装，并判断何时袭击更有利。母体没有天生无法按按钮或无法给人打针的破绽。

主动显形会打破维持普通体态的约束，形成更强的猎手组织。变化造成不可逆的外观和组织损伤，因此本版显形后不能立刻缩回完整人类状态。它仍能借雾和地形躲藏，不能让已经目击的人忘掉刚才发生的事。

母体的目标是让感染网络继续存在，阻止未转化人员脱离控制并把完整证据带走。它不需要每局把人全杀完才有行动意义：逼弃一人、阻止一条路线或停下 W-7 都能改变最后结果。

## 4. 母体可被击杀，复活网络为何随之断开

母体是有生命组织的核心，不是无法伤害的幽灵。显形后可被枪械和战术配合击杀，生命耗尽即失去核心。它不会通过变回伪装、重新开面板或切换区域重新获得一条命。

感染节点依赖母体维持组织协调和重建。普通感染者被击倒后，可由节点重建战斗个体；原玩家继续操纵这个感染角色，保持参与感。核心消失后，节点失去重建能力，但已经活动的感染者不会凭空消失。

人的感染期同样不会因为远处母体死亡立即痊愈：已进入体内的病原仍可能完成转化。所以“打死母体”与“完成清剿”有明确区别。清剿必须处理现存感染者、正在孢化的人和还没被治疗的感染期。

双母体代表两处稳定核心，任一存活仍可维持网络。一个核心毁坏后，该玩家可以在另一核心存在时以普通感染者继续参战；最后核心损毁后，没有新的核心可接替。这解释了角色降级，并避免双母体互相无限复活为完整母体。

未显形母体的身体仍使用人类濒危表现，可以被队友扶起；这为真实伪装付出了接受治疗、暴露位置和等待救援的代价。倒地时不能显形换生命。显形猎手则不再拥有这套人类救援状态。

友伤关闭、生命数值和起身保护属于公平性与可读性的游戏约定，不写成“手枪能神秘识别所有坏人”的剧情设定。否则故事会反过来破坏隐藏身份的逻辑。

## 5. 感染、救援与药物为什么分开

伤口和病毒扩散是两个问题。扶起让人重新活动，绷带处理伤势，解毒剂阻止尚未完成的感染过程；三者不能随意互相替代。

感染期意味着病原尚未完全接管宿主。玩家能够判断、协作、求救，甚至冒险完成最后一步任务。只有不可逆孢化之后才由感染网络接管，开始新的阵营目标。

解毒剂是应急阻断药，不是恢复已被重构人格和组织的万能复活药。它能挽救感染期幸存者，不能把已经转化的敌人重新变回队友。稳定感染只是争取处理时间，不能无限延长这种临界状态。

每人的可救倒地次数与精确秒数是游戏压缩，不用病历解释“第二次必定只剩某个秒数”。剧情只表达重复创伤使情况恶化，规则界面负责准确告知剩余机会。

## 6. 为什么需要恢复供电与修复通讯

主发电机的保护回路因事故断开，需要找回备用模块。维修端与地面维护站原本就是同一设施的检修入口，因此玩家能从不同位置恢复同一台设备，不必为了反守点虚构另一台无限发电机。

供电恢复后，门禁转入应急开放、桥电机启动、实验区照明恢复；隔离通路中必须保留机械逃生出口。主线关键物资不放在自己要修的门后，这是设施应急设计，也是玩法可达性要求。

信号塔的收发模块、天线校准和供电分别承担不同工作，所以可以提前准备、最后汇合呼叫。通讯技术员的便携中继只增加已修好系统的操作入口，不凭空修复整套通讯网络。

任务确认进度代表已经装好的物理部件和恢复的设置。感染者可以攻击操作者、制造局部短路，却不会因为站在旁边就让已经安装的零件从世界消失。

## 7. 为什么直升机有两个落点、信号弹有什么用

外部接应单位知道设施有屋顶和离岛两个应急登载区，却无法仅凭旧坐标判断现场烟尘、灯光、通路和地面人员情况。求救广播能建立接应，信号弹提供地面引导与占用确认。

没有信号弹时，机组依据本次风向、能见度和结构可达性选择一个合适落点。玩法中的随机选择代表这些局部差异，不代表飞行员不认识停机坪。锁定后必须广播，不能为了惊吓玩家临时改点。

接应只能停留有限时间，否则会暴露于失控设施与封锁风险。固定的候机窗口让落点争夺有明确终点；没有人能坐进飞机就让全体同伴立刻被迫结算。

载具的应急检疫设备能识别完整母体组织特征，便携药物与普通人员扫描器没有这种分析能力。急性感染期可由隔离运输和离岛医疗处理，已整合的母体不能按同样风险接收。游戏中的 3 秒登记是流程压缩，不把它写成现实医学保证。

港口工作船和研究潜艇是设施认证载具，也有同类离岛检疫流程；设备随实际离港准备启动。它们不是拿一张个人身份证就能绕过封锁的普通木船。

## 8. 为什么船和潜艇有不同任务

船是近岸物流设备，普通工作人员都有应急操作权限。它拥有独立发动机，因此可不修主发电机，但必须找到发动机组件和燃料，并解决跨岛运输。桥的机械绞盘与常开维护栈道解释停电时仍有代价较高的通行办法。

潜艇属于地下试验运输系统，涉及密封、压力和授权。普通岗位可以进行应急操作，但启动资格由当班高级授权员掌握。松狮是本次仍在岛上的授权员，所以需要找人、护送并完成虹膜确认；不是要求玩家刚好抽中某个科学家职业。

松狮会被袭击、躲避和停下来等待。他的倒地不是无限次死而复生，表现上是失去行动、需要帮助；自动退回已到达节点是防止 NPC 永久卡死的游戏兜底，不宣称剧情里有人会瞬移。

本局路线不可用代表事故已经造成无法在撤离窗口内修复的船体/密封系统损伤。状态板必须如实告知，而不是让玩家耗费整局寻找不存在的最后一件零件。

## 9. W-7 为什么存在，为什么罕见

Site-7 的地下核心保留了一套军工级最终净化装置，代号 W-7，其中包含能够毁灭地下病毒源与地面设施的核爆载荷。它从未属于员工正常逃生手册，也不会在每次事故中自动可用。

本次事故中，只有少数设施受损配置保留了完整的安全联锁、有效巡检记录和可恢复授权链；R1 用 10% 的开放概率表达这种稀有组合。场景里的封存装置可以一直存在，有效的启动调查链不必每局存在。

公司将入口藏在维护记录里，因为该装置意味着连同研究成果一起销毁。巡检条提供真实、可推理的线索；读者需要结合库位、样本记录和副控日志找到完整授权。这构成少数对局中的深层探索，不是每局开场必做的三份文件任务。

两人同步授权是防止单人误启动的安全联锁。申请后的公开倒计时与否决渠道让其他工作人员知道即将发生什么；玩家可以反对被他人的彩蛋强制提前结束。已取得授权者可以留下防守，形成牺牲结局；最后一人不必凭空绕过双人联锁。

W-7 的机械停机端在装置进入倒计时后可见，这是应急停机设施，不需要感染者突然懂得破解全部公司密码；感染者可以破坏控制过程，使净化失败。最后阶段不可逆，解释临近爆炸时不能再通过一个按钮全部恢复。

炸毁病毒源不会让已经死去的同伴活过来。结局必须同时告诉玩家：多少人获救、感染是否完成封锁、病毒源是否摧毁。把“无人获救的牺牲”包装成比全员逃生更高一级的普通胜利，会改变玩家动机，本版不这样处理。

## 10. 为什么有全局时限

广播中的 22 分钟代表外部封锁窗口即将关闭，接应载具必须离开危险海域和空域。幸存者无法无止境地把整座岛搜空、等待全部技能恢复或与感染者永久僵持。

时限到达记“未能在封锁前离岛”，不必把所有玩家描绘成在同一瞬间爆炸或同时病毒突变。W-7 爆炸是另一个实际毁灭事件，表现必须区分。

18 分钟警告给出最后路线规划机会。直升机最后呼叫早于全局截止，是因为实际飞行与登载需要时间；船和潜艇若已经接近准备完毕，仍可利用较短启动流程。这种差异来自交通工具，而非系统突然偏袒某条路线。

## 11. 剧情如何出现在游戏里

| 时机 | 最多传达什么 | 对玩法的作用 |
|---|---|---|
| 宿舍醒来 | “通讯中断，封锁窗口有限；去大厅查看供电任务。” | 立即形成目标，不用先看长片 |
| 首次接近仓储 | 模块标识、维护路线、物资用途 | 教会探索和搬运 |
| 母体觉醒 | 只向母体说明当前身份与行动选择 | 支撑伪装，不公开泄底 |
| 第一次感染期 | “阻断药可救，伤口处理不能清除病原。” | 解释双状态与救援 |
| 供电完成 | 灯光恢复、松狮呼救、桥可启动 | 让进展可见，打开额外机会 |
| 松狮被找到 | 一两句授权与地下海信息 | 推动护送，不讲完公司历史 |
| 首次转化 | 原人类目标关闭、新阵营任务出现 | 消除“我现在该帮谁”的困惑 |
| 求救成功 | 进近消息与落点锁定倒计时 | 组织会合与终局转移 |
| 罕见巡检条 | 具体库位线索，不直接写“集齐三张就核爆” | 引发有方向的发现 |
| 最终结算 | 人员去向、病毒源状态、一段对应结局 | 给选择后果，不否定玩家成绩 |

背景录音和文档可反复查看，但不在追逐中强制打开长对话框。第一次阅读不暂停全服、不授予无敌。关键操作信息始终由界面负责，剧情补充原因。

## 12. 与基岩版的关系

Java 版定位为设施事故发生阶段的独立前传分支。松狮未能乘潜艇离开时，可作为后来仍留岛的线索；若玩家成功救走他，则给出另一条可能结局。不要先规定他必须留下，再让潜艇玩法无论怎么做都失败。

船员主题、海风号后续事件和旧 NPC 可在文件或离岛尾声出现，但不要求新玩家知道基岩版才能理解当前目标。对老玩家的呼应应该是额外发现，不承担主线规则说明。
